# Debate benchmark

Для каждой задачи из `tasks.json` сохраните три ответа: A — одна сильная модель,
B — независимые ответы N моделей и один синтез без критики, C — полный прогон
схемы Basic. Скопируйте их в `runs/<taskId>/A.md`, `B.md`, `C.md`, затем выполните
`node benchmarks/collect.js --input benchmarks/runs`. Для оценки используйте
`rubric.md`, открывая только `comparison.md`; соответствие blind-меток конфигурациям
хранится в `key.json`.

B запускается схемой Basic из одного раунда и синтеза; если схема добавляет
критический раунд, это расхождение фиксируется в отчёте benchmark.
