# План сборки

Один порядок вместо трёх исходных. Этап не начат, пока не пройдены ворота предыдущего. Номера тестов — из [../verification/05-acceptance.md](../verification/05-acceptance.md).

| Этап | Что собирается | Ворота |
| --- | --- | --- |
| С0 | Рецензия методологии (`11-methodology-review`) по четырём документам; утверждённые патчи внесены | Ни одного незакрытого замечания, чья проверка показывает нарушение ядра |
| С1 | Папка задачи; цепочка хешей; команды из руководства; внешний наблюдатель назначен | Тесты 1, 6 |
| С2 | Схемы установлены в Basic; восемь моделей отвечают; прогон `1-task-card` и `2-preflight` на учебной задаче | Все шаги получили ответ; доля шагов без ответа измерена |
| С3 | Корпус порч: сорок элементов; калибровка (`7-calibration`) | Тест 9; пороги проверяющих записаны до калибровки |
| С4 | Полигон: двадцать задач ряда А и десять ряда Б (`10-polygon`), три набора | Задачи прошли проверяющего; финальный набор у наблюдателя |
| С5 | Цикл (`4-cycle`) на отладочном наборе; посевы | Тесты 2–5, 7, 8, 10, 12–16, 24–26 |
| С6 | Настройка (`3-setup`) и первый настоящий цикл; канал возражений; аудит и красная команда (`8-audit`) | Тесты 11, 28–30, 32, 33; замер шума на зачётном наборе |
| С7 | Перестройка (`5-rebuild`, `6-rebuild-verdict`); три плеча; библиотека | Тесты 17–23; наименьшая версия оценки дала исход |
| С8 | Выход (`9-exit`) на первой задаче; пост-мортем; неделя работы | Тест 34; итог утверждён; финальный якорь отправлен |
| С9 | Непрерывный режим — после появления в Basic пунктов 1–4 из [../process/04-endless-mode.md](../process/04-endless-mode.md), §4 | Ворота включения режима из §5 того же документа |
| С10 | Вторая задача: перенос приёмов и перестроек | Kill переноса проверен; итог записан как «подтверждено» или «не подтверждено» |

## Что делается первым

1. С0: рецензия методологии — до любой задачи.
2. С1: папка задачи и цепочка.
3. С3 и С4 идут параллельно: корпус порч и полигон не зависят друг от друга.

## Что отложено и до какого признака

| Что | Признак, по которому вводится |
| --- | --- |
| Профили моделей по измеренным исходам | Накоплено не меньше двадцати циклов; замена модели в роли обсуждается чаще раза в период |
| Удаление ролей по полезности | После С7: есть замер шума и парные прогоны |
| Вторая активная задача | Одна задача стабильно проходит неделю без вмешательства |
| Двойная подпись владельца и наблюдателя на перестройках | Первое заявление статуса выше S2 |
| Параллельные ветки в одном цикле | Три ветки регулярно ждут друг друга |
| Расширение меню методиста | Архив отклонённых предложений накопил повторяющийся тип |
| Исполнение проверок вне моделей | Появление в Basic исполнения кода или отдельной программы проверки |
