# Форматы данных

Машинные форматы — JSON Schema (draft 2020-12) в [schemas/](schemas/). Описание каждого поля — в самом файле.

## 1. Форматы

| Формат | Файл | Кто пишет | Где живёт |
| --- | --- | --- | --- |
| Карточка задачи | `task-card` | владелец | `core/task-card.json` |
| Пороги ядра | `thresholds` | владелец на этапе Э2 | `core/thresholds.json` |
| Замок ядра | `core-lock` | владелец | `core/lock.json` |
| Конфигурация | `config` | сборщик конфигурации, подпись владельца | `config/C<n>.json` |
| Карта вопроса | `question-map` | секретарь журнала | `state/map.json` |
| Гипотеза | `hypothesis` | генератор | запись цикла |
| Заявка на проверку | `claim` | экспериментатор | запись цикла |
| Вердикт | `verdict` | секретарь журнала по ответам проверяющих | запись цикла |
| Факт | `fact` | обработчик источников | запись цикла |
| Противоречие | `conflict` | секретарь расхождений | запись цикла |
| Пробел | `gap` | координатор, исполнитель проверки | запись цикла |
| Яма | `pit` | секретарь журнала | запись цикла, `library/pits/` |
| Предложение изменения | `change-proposal` | методист, изобретатель, плацебо | запись цикла |
| Запись библиотеки перестроек | `rebuild-record` | библиотекарь | `library/rebuilds/` |
| Передача и квитанция | `handoff` | передающая и принимающая роль | в ответе шага |
| Запись цикла | `journal-entry` | секретарь журнала | `journal/records.jsonl` |
| Донесение контролёра | `control-report` | контролёр | запись цикла |
| Решение владельца | `owner-decision` | владелец | запись цикла |
| Итоги ветки | `branch-summary` | секретарь журнала | запись цикла |
| Сводка | `digest` | докладчик | `state/digest.json` |
| Элемент корпуса порч | `corpus-item` | владелец, наблюдатель | `sealed/corpus/` |
| Задача полигона | `polygon-task` | генератор миров, владелец | `polygon/`, `sealed/` |
| Итог задачи | `final-report` | составитель итога | `out/final.json` |

Имя файла схемы: `schemas/<файл>.schema.json`.

## 2. Правила

1. Номера объектов: `F` факт, `G` гипотеза, `H` заявка, `V` вердикт, `K` противоречие, `P` пробел, `Y` яма, `X` предложение изменения, `L` запись библиотеки. Нумерация сквозная по задаче; номер не переиспользуется.
2. Запись не правится. Исправление — новая запись с полем `corrects`.
3. Каждая запись несёт `config_id`. Записи разных конфигураций напрямую не сравниваются; при перестройке их судьбу определяет карта переноса.
4. Шаг, который отвечает в формате JSON, Basic проверяет сам: обязательные поля заданы в схеме шага. Ответ без них возвращается модели на исправление.
5. Шаг, который отвечает текстом, обязан содержать заголовки, заданные в схеме шага. Секретарь журнала переводит текст в записи; контролёр сверяет.
6. Текст карты вопроса в пакете цикла — те же поля, что в `question-map`, в виде разделов. Предел — 8 000 знаков.

## 3. Папка задачи

Одна папка на задачу. Место выбирает владелец; модели к папке доступа не имеют.

```
<задача>/
  core/          task-card.json · thresholds.json · lock.json · sealed-test.txt
  config/        C0.json · C1.json · …           все версии, ни одна не удаляется
  state/         map.json · digest.json · package.txt   текущий пакет цикла
  journal/       NNNN_<схема>_<дата>.json · chain.txt · records.jsonl
  runs/          <схема>_<дата>/{schema,artefacts,exports,notes}
  polygon/       открытые задачи полигона
  sealed/        corpus/ · scored/ · seeds/       закрытые наборы
  out/           final.json · пакет воспроизведения · пост-мортем
```

Постоянная память хранится отдельно от задач: `library/pits/`, `library/rebuilds/`, `library/techniques/`. В неё попадает только то, что прошло правило трёх независимых подтверждений.

Финальный набор в папке задачи не хранится: он у внешнего наблюдателя.

## 4. Пакет цикла

`state/package.txt` собирает владелец перед запуском цикла из трёх частей в таком порядке:

```
=== ЯДРО (версия N, только чтение) ===
Задача · Признак решения · Чем проверяем · Чем не проверяем · Ограничения ·
Kill-критерии · Пороги · Остаток бюджета · Номер цикла

=== КОНФИГУРАЦИЯ C<n> ===
Диагноз барьера · Ведущая валюта · Представление задачи · Правило выбора шага ·
Приёмы ролей (по коду роли) · Изменяемые пороги · Карантин

=== КАРТА ВОПРОСА ===
разделы формата question-map
```

Предел пакета — 12 000 знаков. Во время карантина в раздел конфигурации добавляется подраздел «Прежняя конфигурация» с приёмами, которые изменены.
