## Как читать

**Состояние 2.81.950 (L-15, L-5).** Таблицы: pipe-таблица есть у всех провайдеров, для которых есть фикстура таблицы (GPT, Grok, DeepSeek, Qwen), остальные — по тому же правилу движка. Текстовый путь без движка (резервный текст из HTML): таблицы превращаются в pipe-таблицы через `replaceTablesWithMarkdown` в `content-claude.js` (`extractResponseText`), `content-chatgpt.js` и `content-perplexity.js` (`cleanContent`). Плоский `answer` (M-6) сохраняет структуру блоков: `AnswerStructure.linearizeText` ставит `\n\n` между абзацами и блоками, `\n` между пунктами списка, строками таблицы и после `<br>`, ячейки таблицы разделяет ` | `, код `<pre>` сохраняет свои переносы; пробелы внутри строки схлопываются. Фоновый `getText` (`background/job-orchestrator.js`) сохраняет переносы `innerText`. До M-6 весь плоский текст шёл одной строкой. Приёмка, метки и подтверждение работают по тем же словам. Общий переход Basic на markdown: `shared/basic-reply-text.js` берёт копию, если она полная и совпадает с плоским текстом; порог длины 25 % (см. `docs/Transport/message-delivery.md`). Perplexity: `a svg` в чипах источников — декор, копия не неполная (живой скелет). Z.ai и Kimi не имеют `cleanContent`: копия идёт через конвейер финализации (`UnifiedAnswerPipeline.extractAnswerMarkdown`), правила `Z.ai`/`Kimi` есть в `shared/answer-markdown-providers.js`; код и Mermaid у них не проверены на живой разметке.

- **Сегодня** — что проходит в `answer` (текст) и `answerHtml` по текущему коду; копия `answerMarkdown` в таблицах ниже не учитывается (состояние 2.81.950 — выше). Значения: *полностью* / *частично* / *не сохраняется*; «не проверено» — без данных даже для оценки.
- **После работ** — цель по спецификации (не обещание: достигается при WP1–WP5 и закрытии пробелов «не проверено вживую»).
- **Проверено** — «фикстура» = структура подтверждена скелетом из репозитория (и/или фикстурой WP4); «не проверено вживую» = утверждение выведено из кода, живой DOM не снимался.
- Механика, общая для всех провайдеров: `answer` схлопывает пробелы ([answer-structure.js:14-16, 72-110](../../content-scripts/answer-structure.js)); `answerHtml` — клон с inline-стилями, из которого удалены `script, style, noscript, svg, canvas, button, [role=button], [aria-hidden=true], [inert], header, footer, nav, aside, form` ([content-utils.js:1236-1264](../../content-scripts/content-utils.js)); затем DOMPurify ([results.js:96-103](../../results.js)).

Общая эвристика для всех (в т.ч. неподтверждённых): `<pre>`/`<pre><code>`, язык из `language-*`/`lang-*`/`data-language`, иначе подпись коротким отдельным узлом в шапке (≤40 символов вне `<pre>`), номера строк (`.line-numbers`, `.linenumber`, `[class*=line-number]`, `.cm-gutters`) и кнопки не попадают в текст; одиночный `<code>` блоком не считается; обёртка таблицы = элемент, где вне `<table>` нет абзацев/заголовков/списков/`pre`.
