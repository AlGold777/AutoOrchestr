## Порядок работ

1. **Pointer вместо for-of.** Исполнение pc по ref; линейный next сохраняется без route. Visits увеличиваются только при новом заходе, не retry. Старые последовательность и callbacks сохраняются.
2. **Gate.** Criteria, pass all/any, техническая приёмка и require прежде вердикта. Text/JSON verdict по 6.1; отсутствие/неверный verdict повторяется. OnFail stop/ask, нормализация сокращённого goto. Gate не занимается выбором трёх направлений автоматически.
3. **Rule selector.** Eq/in/exists, all/any, строгие JSON-значения, source+pointer. Никакого eval. Missing не совпадает eq/in. Multiple/zero matches имеют ровно поведение 6.2; implicit first запрещён.
4. **Model/owner selector.** Model phase route возвращает JSON route ID. Invalid ответ повторяется; иначе owner decision, не otherwise. Owner callback разрешает только заданные ID; Stop/invalid/null не продолжают прогон.
5. **Action.** Goto/stop/return, журнал с case ID/источником/причиной; validate targets до запуска. Unknown runtime target — ошибка без отправки. Линейный next после goto не выполняется дополнительно.
6. **Feedback.** Разрешить выбранные версии ДО invalidate, зафиксировать адреса; передать отдельным блоком только новому заходу цели. Не включать эту передачу в обычную проверку «источник раньше потребителя». Первый заход цели её не видит.
7. **Invalidation.** При backward goto invalidate target и явные refs; распространить по фактическим dependencies на результаты/артефакты. Invalid версии остаются в истории. Повторный failed/skipped не восстанавливает старую актуальность. Required downstream прекращает отправку.
8. **Cycles.** Counter key routeRef+caseID; maxLoops ограничивает фактические обратные переходы. Лимит до перехода. Схема return-графа проверяется с A01; полный граф без bounded edges должен быть ацикличен. Self-loop также ограничен.
9. **CHG.** ResumeAt push, return pop, вложенный стек. Возврат после G1 идёт к сохранённому S19, а не автоматически через все S14–S18. Но недействительные необходимые входы обязаны пересчитаться заданным маршрутом; нельзя обходить requirement ради краткого пути.
10. **Snapshot contract.** Передать A05 pc, visits, current phase, counters, stack, feedback, dependencies и registry validity в сериализуемом виде. Обязательно отметить точки, где решение уже совершено, а следующий шаг ещё не отправлен.
