# Движок Basic и схемы pipeline

Статус: **концепция согласована 9 октября 2026**, ещё не реализована.
Текущая реализация движка описана в [custom-pipeline.md](custom-pipeline.md).

## Термины

- **Basic** — универсальный движок pipeline (бывший Custom). Basic — это код движка вместе с его
  значениями по умолчанию. Это единственный pipeline, который исполняется.
- **Схема** — pipeline, созданный на базе Basic. Схема не содержит кода и не является копией
  pipeline. Это слой поверх Basic: она хранит только то, чем отличается от Basic
  (раунды, модели, роли, задания, входы, политика запуска).

## Как исполняется схема

При запуске берутся текущие значения Basic по умолчанию, на них накладывается схема,
и движок исполняет результат. Поле, которое схема не задаёт, получает значение Basic.

Save сохраняет схему, а не новый pipeline.

## Происхождение схемы

Поле `origin` в схеме:

| `origin` | Кто создаёт | Свойства |
| --- | --- | --- |
| `builtin` | Мы | Поставляется с кодом, для пользователя только чтение |
| `user` | Пользователь | Хранится у пользователя, мы её не перезаписываем |

По устройству схемы обоих типов одинаковы.

## Правила развития движка

1. **Движок не знает о конкретных схемах.** Если схеме нужна новая возможность, она
   добавляется в Basic как общее поле или вариант значения и доступна всем схемам.
2. **Схема задаёт только то, что умеет Basic.**
3. **Новое поле по умолчанию сохраняет прежнее поведение.** Новое поведение схема
   включает явно.
4. **Существующее значение по умолчанию не меняется молча.** Его изменение меняет все схемы,
   которые это поле не задают. Поэтому такое изменение — отдельное решение, и до него
   называется, какие схемы оно затронет.

## Чего не делаем

Старые pipelines (Polishing, Delta, Test, Research, Architecture и ранее сохранённые копии)
не чиним и не переносим. При необходимости их заново описывают как схемы на Basic.
