# Pipeline Delta: игра словами

Версия: **2.81.627, 7 октября 2026**.

**Модели по очереди добавляют к фразе по одному слову; дальше передаётся только изменение.** Начальная фраза —
сообщение в поле ввода, иначе тема чата.

| Параметр | Значение |
| --- | --- |
| Идентификаторы | `presetId: DELTA`, `runner: 'delta'` |
| Круги | Раунды canvas; по умолчанию 3 (`roundLimit: "3"`) |
| Порядок ходов | Модели круга по очереди, в порядке на canvas |
| Код | [`disput/delta-pipeline.js`](../../disput/delta-pipeline.js), `runDeltaFromPage` в [`results.js`](../../results.js) |

## Как работает

Пример: модели A, B, C, фраза «Утром кот».

1. **Первый ход модели — вся фраза.** A получает «Утром кот» и отвечает «вышел».
   B получает «Утром кот вышел», C — «Утром кот вышел на».
2. **Следующие ходы — только новые слова.** Во втором круге A получает только
   «на крышу»: остальную фразу она помнит в своём чате.
3. **Модель не ответила** — на следующем ходе она снова получит всю фразу:
   её чат мог потеряться.
4. **Ответ — одно слово.** Берётся первое слово ответа; кавычки, выделение и
   метка доставки словом не считаются. Если слов больше, остальные отбрасываются
   (в журнале хода `extra`).
5. После остановки в ленте появляется карточка **Delta**: фраза целиком и кто
   какое слово добавил.

Общее ограничение длины ответа к промпту не добавляется: игра сама просит одно слово.

## Новый чат для каждой модели

Каждая модель начинает игру в новом чате (если включены новые страницы), дальше
пишет в ту же вкладку. Раньше транспорт открывал новые страницы только при первой
отправке прогона, и при поочерёдных ходах новый чат получала лишь первая модель.
Теперь это учитывается для каждой модели (`newPagesModels` в `runModelBatch`).
Это касается и других pipelines: модель, впервые вызванная в позднем этапе,
тоже открывается в новом чате.

## Остановка

- пройдены все круги canvas (`rounds_done`);
- за круг ни одна модель не добавила слово (`all_failed`);
- Stop: пока идёт игра, кнопка запуска показывает Stop и прерывает прогон; фраза, собранная к этому моменту, остаётся в итоговой карточке.

Вложения уходят только с первым сообщением каждой модели.
