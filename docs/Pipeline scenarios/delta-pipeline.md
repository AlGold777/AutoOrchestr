# Pipeline Delta: сбор улучшений идеи

Версия: **2.81.623, 7 октября 2026**.

**Delta собирает только свежие улучшения исходной идеи.** Идея не меняется.
Слияния, дедупликации по смыслу, оценки и синтеза нет: результат — растущий
список строк. Всё это делается вне pipeline.

| Параметр | Значение |
| --- | --- |
| Идентификаторы | `presetId: DELTA`, `runner: 'delta'` |
| Круги | Раунды canvas; по умолчанию 3 (`roundLimit: "3"`) |
| Порядок вызова | Модели круга по очереди, в порядке на canvas |
| K | Не больше 3 улучшений на ответ (`deltaMaxIdeas`) |
| Длина ответа | Не более 300 слов (защитный предел) |
| Код | [`disput/delta-pipeline.js`](../../disput/delta-pipeline.js), `runDeltaFromPage` в [`results.js`](../../results.js) |

## Как работает

1. Идея — сообщение в поле ввода, иначе тема чата.
2. В каждом круге модели вызываются по одной. Промпт: идея, **весь** нумерованный
   список, собранный к этому моменту, и инструкция: «Предложи только новые улучшения
   по существу идеи, которых нет в списке выше… Каждое улучшение отдельной строкой,
   не больше K. Если новых нет, не пиши ничего, кроме метки.»
3. Ответ делится на строки: одна строка — одно улучшение. Убираются маркеры списка
   и нумерация, пустые строки, отказ вида «Новых улучшений нет» и точные повторы
   строк списка. Остальное сразу дописывается в конец списка с автором и кругом.
   Превышение K не обрезается: строки принимаются все, в журнале — `overLimit`.
4. После остановки в ленте появляется карточка **Delta** с итоговым списком.

## Метка и сбои

Метку `[[AO-xxxxxx]]` и инструкцию «Последней строкой ответа напиши только метку»
добавляет общий транспорт ([`shared/message-delivery.js`](../../shared/message-delivery.js)).
Ответ с чужой меткой (устаревший) транспорт отбрасывает. Ответ без метки
**принимается**: даже часть предложений полезна.

Статус ответа в журнале прогона: `OK` — добавлены строки; `EMPTY` — ответ есть,
нового нет; `FAILED` — нет текста, ошибка или таймаут. Упавшая модель пропускается,
цепочка идёт дальше; отдельного повтора нет — модель снова вызывается в следующем круге.
Таймаут и повторы внутри вызова — общие значения транспорта.

## Остановка

- пройдены все круги canvas (`rounds_done`);
- круг не добавил ни одной строки: `no_new_ideas`, если хоть одна модель ответила,
  `all_failed`, если не ответил никто;
- Stop: пока идёт Delta, кнопка запуска показывает Stop и прерывает прогон.

## Почему не движок Debate

Delta вызывает `runModelBatch` напрямую, как судья и сообщение модератора.
План, StateMap, приёмка этапов и ContextBroker ему не нужны, а ContextBroker
отбирает контекст по бюджету — модель не увидела бы часть списка и повторяла бы
идеи. Новые вкладки, вложения (только в первом сообщении каждой модели), метка
и Stop — общие механизмы страницы. Если общий бюджет контекста превышен,
транспорт сокращает промпт с явным уведомлением.

## Вне первой версии

Параллельные микрогруппы (параметр S), остановка по объёму токенов, повтор
упавшей модели в конце того же круга, K в интерфейсе.
