# F03 · Транспорт участников

Это самостоятельное задание на исправление. Общие контракты и точные критерии обязательны: [ТЗ исправлений](../basic_fixes_oct12_technical_spec.md). Основание: [отчёт проверки](../basic_review_oct12.md).

- Ответственность: R01/R05/R06; транспорт N04; N06.
- Файлы: `background/job-orchestrator.js, background/tab-manager.js, адаптер Basic в results.js`. Общие файлы не менять до передачи владельцем.
- Зависимости: Background можно начать сразу; страницу менять эксклюзивно до F05.
- Задание: Обеспечь строгую привязку run+participant, адресные вложения по чату, запрет stateless API для participant chat. Сделай read-only проверку сохранённой попытки и передай контракт F05.
- Прочитать и выполнить критерии разделов: R01/R05/R06, N04/N06 общего ТЗ.
- Передача: F05 actual bindings, request ID и callback проверки, сериализуемое состояние доставки; F06 причины отказа.

## Порядок выполнения

1. Прочитай AGENTS.md, basic-start-here.md, общее ТЗ исправлений, указанные разделы исходного ТЗ и отчёт. Проверь git status/HEAD; не перезаписывай чужие изменения или уже исправленный код.
2. Воспроизведи дефект/ограничение на production-пути. Добавь проверку, которая падает до исправления и проверяет результат, источник и отсутствие лишней отправки. Не зеркаль реализацию тестом.
3. Внеси минимальное исправление по общему контракту. Если нужно изменение чужого модуля, передай запрос его владельцу с примером; не вводи второй контракт.
4. Выполни положительные/отрицательные проверки, старую совместимость и связанные round-trip сценарии. Не заменяй недостающую проверку существующим зелёным тестом.
5. Обнови соответствующие документы и версии при кодовых изменениях, сохрани самостоятельный commit по правилам AGENTS. Передай владельцу следующего пакета commit, интерфейсы, JSON-пример и команды с результатами.

Готовность: каждый назначенный пункт имеет доказательство из общего ТЗ; незавершённые зависимости названы явно. Отчёт без исправления не считается завершением задания. Не заявляй реальную доставку провайдеру по mock-тесту.
