# Ноль падений полного набора

## Цель и приёмка

Задание User: не оставлять никаких падений. Исходное состояние — `c85baa9f`, версия 2.81.919; точка возврата `before-zero-test-failures-20261028`. В рабочем дереве есть пользовательские неотслеживаемые материалы в `docs/`; они не входят в работу.

Критерий завершения — полный `npm test` на итоговом сохранённом состоянии с нулём падений. Ранее известная нестабильность не является исключением. Нельзя скрывать ошибки новыми `skip`, `todo`, исключениями файлов, удалением содержательных assertions или увеличением таймаута вместо устранения причины.

Действующие контракты Basic: участники и их ID определяются схемой; выключенные участники сохраняются; роли, личные запросы и дисциплина не переносятся между участниками; сохранение и экспорт сохраняют объявленные данные. Изменения контрактов ради зелёного теста не допускаются.

## Шаги

1. Исправить окружение большого теста страницы: явно объявлять участников, восстанавливать состояние между сценариями и создавать полноценные списки ролей. Сохранить проверки передачи, ролей, сохранения и экспорта. После этого разобраться с каждым оставшимся отказом: исправить дефект либо доказанно устаревшее ожидание.
2. Устранить повторную полную перестройку страницы при загрузке большой схемы. Проверить S01–S30 с исходным deadline и сохранность участников/настроек/порядка.
3. Заменить устаревшую проверку буквальной строки фильтра проверкой поведения и сделать зависимые от реального времени проверки детерминированными при необходимости.
4. Обновить версию и документацию, независимо проверить diff, выполнить полный набор без исключений и сохранить самостоятельные изменения отдельными коммитами.

## Разделение работы

- `tests/results-debate-favorites.test.js`: один исполнитель; остальные агенты этот файл не меняют.
- `results.js`, `pipeline/pipeline-runtime.js`, отдельная проверка производительности: один исполнитель.
- `tests/release-log-regressions.test.js`, `tests/false-success-watcher-guard.test.js`: отдельный исполнитель и проверяющий полного набора.
- Версия, общие документы и приёмка: ведущий. Тесты и сохранение поручаются GPT-6 Luna high.
