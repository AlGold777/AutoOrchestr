# Basic: план исправлений по ревью пользовательских схем (27.10.2026)

Источник — ревью движка Basic для пользовательских схем на версии 2.81.903 (пять независимых проверок, 153 сценария, 40 тыс. случайных искажений схем). Номера пунктов (п. N) — номера проблем в ревью.

Главная причина большинства дефектов: запуск исполнял не сохранённую схему, а схему, заново собранную со страницы, и правки холста не попадали в запись. Цель плана — схема снова исполняемая истина: что установлено и сохранено, то и запускается, и данные пользователя не теряются.

Порядок: сначала то, что теряет данные, затем единая схема (она снимает целый класс дефектов), затем шаги User, продолжение прогона, совместимость и инструкция. Каждый этап — отдельные коммиты с подъёмом версии, документацией и тестами; этап считается сделанным, когда он в основном чекауте.

Статус: ☐ — не начато, ◐ — в работе, ☑ — сделано (версия).
