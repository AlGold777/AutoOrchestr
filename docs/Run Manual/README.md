# Ручной прогон без расширения

Всё, что нужно агенту, который ведёт прогон схемы через открытые вкладки моделей. Расширение AutoOrchestr в таком прогоне не используется.

| Файл | О чём |
|---|---|
| [manual-run.md](manual-run.md) | регламент координатора: подготовка, режимы, окна, ввод, мониторинг, замена моделей, артефакты, отчёт |
| [manual-run-orchestration.md](manual-run-orchestration.md) | порядок отправки, обход вкладок, прокрутка до начала ответа, приёмка, сбои |
| [universal-five-step-scheme.md](universal-five-step-scheme.md) | универсальная схема из пяти шагов с готовыми запросами |
| [model-modes.md](model-modes.md) | состав моделей и режимы, которые выставляют на сайтах |

Наблюдения о поведении сайтов — в [Platform specifics](<../Platform specifics/README.md>), общий каталог. Материалы каждого прогона — в `docs/Run Automation/Test_run/<Task_Name>_<YYYY-MM-DD>/`.
