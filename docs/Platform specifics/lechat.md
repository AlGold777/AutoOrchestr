# Le Chat (провайдер Le Chat)

Код: `content-scripts/content-lechat.js` (версия скрипта `v6.1.4`, `:8`), селекторы `selectors/lechat.config.js`. Матрица: `docs/Architecture/answer-markdown-matrix.md` (строка 21). Заготовка от 2026-10-30. Попыток Le Chat в выгрузках `docs/Run/Test_run/*/exports/` нет: факты из кода и реестра, живым прогоном не проверены.

## 1. Отправка

- Первый путь — Ctrl+Enter: комментарий версии `v6.1.4` — «Ctrl+Enter first + provider-real submit proof» (`content-lechat.js:8`).
- Кнопка отправки: `button:has(svg[data-icon="arrow-up"])`, `button:has(svg[data-icon="send"])` (`content-lechat.js:832–833`). Последний резерв — кнопка только с SVG, в пределах формы композера (`:885–891`).
- Кнопка может быть выключена, пока React не зарегистрировал ввод. Код повторно шлёт события `input` и ждёт включения до 2500 мс (`waitForSendEnabled`, `content-lechat.js:901–912`).
- Мягкий гейт готовности кнопки подключён (CHANGELOG 2.81.950; реестр L-7, ЗАКРЫТО-Н, 56c49b11).

## 2. Начало и конец генерации

## 3. Структура ответа

- Корень ответа: `[data-message-part-type=answer]`; рассуждение: `[data-message-part-type=reasoning]` (матрица, строка 21, селекторы репозитория).
- ЛОВУШКА: `data-testid="code-block"` стоит на inline `<code>`, а не на блоке кода (матрица, строка 21; фикстура `lechat.json`). Блок кода по этому атрибуту не найти.
- Блок кода не снят; таблицы не снимаются (матрица, строка 21 и колонка «Таблица»).
- Svg-заглушка для ответа Le Chat — не проверена вживую (реестр L-5).
