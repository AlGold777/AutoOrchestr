## 1. Отправка

- Сочетание клавиш зависит от платформы. На macOS — Cmd+Return (`metaKey`); Windows и Linux — Ctrl+Enter (`content-grok.js:1150–1154`, `1182–1186`). Причина: на Mac Ctrl+Enter иногда не доходит до обработчика Grok (комментарий `:1150–1154`).
- Для страховки на macOS дополнительно отправляется Ctrl+Enter (`content-grok.js:1203–1206`).
- Кандидат кнопки должен быть не `disabled` и видимым (`content-grok.js:627`).
- Мягкий гейт готовности кнопки подключён (CHANGELOG 2.81.950; реестр L-7, ЗАКРЫТО-Н, коммит 56c49b11). В 2.81.949 Grok был без гейта.
