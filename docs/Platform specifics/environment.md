# Среда: macOS и Chrome

## 1. Блокировка экрана превращает все вкладки в скрытые (подтверждено 2026-10-30)

**Наблюдение.** Во время прогона схемы «Ловушка для комаров» на 2.81.950 экран Mac заблокировался в 16:29:36 (`CGSSessionScreenIsLocked = Yes`, `IOConsoleLocked = Yes`, дисплей выключен) и оставался заблокированным до конца прогона. При заблокированном экране `document.hidden = true` и `visibilityState = hidden` даже у вкладки, выведенной на передний план; снимок экрана чёрный.

**Влияние.** Скрытые вкладки получают замедленные таймеры, окна кадров (requestAnimationFrame) не вызываются, активация вкладки не помогает. Скрипты провайдеров с ожиданиями по таймерам (бюджет отправки DeepSeek ~12 с, опрос ответа, визиты) работают минутами вместо секунд. В прогоне попытки 3 и 4 Gemini и DeepSeek (16:35–16:51) шли целиком в этом состоянии: `stream_start_timeout`, `send_failed: send not confirmed`, 17 опросов подряд без ответа.

**Проверка перед прогоном и во время него** (команды в терминале):

```bash
ioreg -n Root -d1 | grep -E 'CGSSessionScreenIsLocked|IOConsoleLocked'
pmset -g log | grep -E 'Display is turned' | tail -3
```

Если в первой команде есть `= Yes` — экран заблокирован, прогон запускать нельзя.

**Что делать.**
- Перед прогоном держать экран включённым: `caffeinate -dimsu -t <секунд> &` (запрет сна дисплея и системы), а в настройках macOS на время работы отключить блокировку экрана/заставку и «Требовать пароль» после выключения дисплея. Автоматическая блокировка через 60 минут (`displaysleep 60`) разблокировать вручную нельзя — пароль вводит только владелец.
- Прогон с заблокированным экраном считать недействительным для проверки транспорта: данные использовать только для диагностики.

**Движок (L-34).** Перед каждой отправкой фон читает `document.visibilityState` вкладки модели; если она не `visible`, пишет `tab_hidden_detected` и предупреждение в журнал модели, прогон не прерывается (`docs/Transport/message-delivery.md`, раздел «Скрытая вкладка»).

## 2. Перезагрузка расширения осиротит скрипты в открытых вкладках

После перезагрузки расширения (chrome://extensions → Reload) скрипты в уже открытых вкладках моделей теряют связь с расширением (`Extension context invalidated`; в журнале `CONTEXT_LOST:context_invalidated`). Вкладки надо обновить (F5) до прогона. С 2.81.951 движок восстанавливает такие вкладки сам (реестр M-4), но обновлять вкладки всё равно надёжнее. Правило процесса — `docs/Agents/agent-live-test.md`, раздел «Обновление вкладок моделей после перезагрузки».

## 3. Лимиты использования моделей

Аккаунт модели может исчерпать лимит (Claude: «Достигнут лимит использования. Сброс в HH:MM», кнопка «Повторить»). С 2.81.949 движок распознаёт это как `usage_limit` и не ждёт ответ. Подключение другого аккаунта — на стороне владельца.

## 4. Скачивания и панель загрузок

Кнопка «Basic» (экспорт прогона) скачивает файл 4–5 МБ и открывает панель загрузок Chrome. Частые экспорты засоряют `~/Downloads` и панель; делайте 2–3 экспорта за прогон.
