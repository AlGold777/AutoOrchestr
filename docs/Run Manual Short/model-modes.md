# Режимы моделей для ручного прогона

Единый источник: какие режимы сайтов моделей должны быть выставлены перед прогоном. Значения даёт владелец. Пустое значение не домысливай: бери режим по умолчанию и запиши это в `notes.md`. Режим читай на странице перед первым сообщением (см. [how-to.md](how-to.md)).

| Модель | Участие в прогоне | Режимы |
|---|---|---|
| GPT (ChatGPT) | участвует (опорная модель) | уровень рассуждений **High** |
| Claude | участвует (автор свода, правки, итога) | модель **Sonnet 5.5** |
| DeepSeek | участвует (отвечает быстро, инженер) | режим **DeepThink ВКЛЮЧЁН**, **поиск ВЫКЛЮЧЕН** |
| Qwen | участвует как инженер на сложных этапах, необязательный | модель **Qwen 3.8**, режим **мышления ВКЛЮЧЁН** |
| Perplexity | участвует как инженер на сложных этапах, необязательный | выбранная модель **Kimi (версия 3, режим размышления)** внутри Perplexity; поиск Perplexity — по умолчанию |
| Mistral (Le Chat) | разрешена | режим **Think** |
| Z.ai | разрешена | модель **GLM 5.3** |
| Grok | разрешена | режим **Build** |
| Gemini | НЕ использовать (слабая, наименее полезная) | — |
| Kimi (сайт Kimi.ai) | НЕ использовать как отдельного участника: Kimi задействован только как модель внутри Perplexity; вкладка kimi.ai в нашей системе вставляется в Perplexity и открывается на `kimi.ai/make3d` (реестр M-15) | — |

Режимы выставляются на сайтах перед отправкой первого сообщения и проверяются по строке на странице. Если у сайта нет точного названия режима («Qwen 3.8», «Kimi 3»), выбирается ближайший доступный по названию с пометкой в `notes.md`.
