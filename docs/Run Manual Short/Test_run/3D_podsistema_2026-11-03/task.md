# Задача прогона

## Задача
Спроектировать инженерно всю работу с 3D в мобильном приложении для анализа техники падела (смэш), уровень конца 2026 года, на переднем крае технологий: захват, распознавание (2D/3D-поза, модель тела, трекинг), реконструкция (метрическое 3D, гравитация, система координат тела, сглаживание, физическая правдоподобность), хранение, сравнение (ученик и тренер под разными ракурсами), показ с вращением на 360° и наложением, проверка качества. Облако, подписка, удаление, юридические вопросы — вне темы. Материалы: materials/s18-3d-plan.md (контекст приложения, вариант автора, вопросы 12.1–12.10).

## Критерии
K1. Решение работает на устройстве (iOS 17+, Android 10+) без собственного сервера анализа; для слабых устройств есть честный упрощённый путь.
K2. Сравнение ученика и тренера не зависит от ракурса камеры и телосложения; неопределённость метрик учитывается.
K3. Каждая модель, SDK и цифра подтверждены источником (URL, версия, дата) или помечены «не подтверждено»; лицензия допускает коммерческое использование.
K4. Передовой уровень конца 2026: решение не повторяет подходы 2022–2024 без обоснования.
K5. Есть способ доказать качество без дорогого оборудования (межракурсная проверка).
K6. План реализуем командой 1–2 мобильных разработчиков и инженера по зрению за 3–5 месяцев; названы этапы и главный риск.

## Форма итога
Документ: разделы по пунктам 1–7 (захват, распознавание, реконструкция, хранение, сравнение, показ, проверка), таблица «пункт | решение | технология и версия | размер/скорость/устройство | лицензия | источник», ответы на вопросы 12.1–12.10, этапы и риски. До 3500 слов.
