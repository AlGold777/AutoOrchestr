# Доставка сообщений (Pipeline)

- Каждый промпт уходит модели с меткой `[[AO-xxxxxx]]`: модель повторяет её последней строкой.
- Ответ со своей меткой — доставлен. Ответ с чужой меткой (устаревший) не показывается. Ответ без метки показывается с пометкой «Без метки доставки».
- В ленте метки, служебная инструкция и маркеры `<<< … >>>` вырезаются — у модератора, моделей и судьи.
- **Judge** (слева от Moderator): после ответов моделей выбранная модель получает их все и даёт итог; её карточка помечена «Judge».
- Журнал — окно телеметрии → **Automation** (кнопка JSON — отчёт). Журнал живёт до перезагрузки страницы.

Код: `shared/message-delivery.js`, `shared/message-delivery-view.js`, точки подключения в `results.js` (`runModelBatch`, обработчик сообщений, `appendDebateFeedEntry`).

## Будущий функционал

- Нет ответа за отведённое время — повторная отправка той же модели.
- Повтор не помог — передача сообщения другой выбранной модели.
