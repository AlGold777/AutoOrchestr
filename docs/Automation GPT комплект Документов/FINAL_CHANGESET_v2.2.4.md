# FINAL CHANGESET — Automation Layer v2.2.4

Status: consolidated after an executable pilot of stages 1–5 (`automation_lab.html`). Supersedes FINAL_CHANGESET_v2.2.3.md where they differ. File names that still carry `v2.2.3` are kept for link stability; their content is v2.2.4.

## Contradictions removed

1. **DPL activation dead end.** Stage 4 requires an ACTIVE DPL, stage 1 creates it as DRAFT, and v2.2.3 had no activation path. Now the runtime issues a `DPL_APPROVAL` QST after the stage 1 commit. The effects `ACTIVATE_DPL` and `RERUN_STAGE` are reserved for runtime questionnaires and applied only by the answer compiler (QANS + AEV AUTHORIZE_POLICY).
2. **PCON activation dead end.** Stage 5 requires an ACTIVE PCON, and no stage activated it. Every created code of stages 1–5 now has `contract.initial_statuses`; PCON is committed ACTIVE.
3. **Empty stage 1/2/4 results were allowed**, although later stages need their objects. Material output is now required and `cardinality` is declared.
4. **The DEFER rule referenced a non-existent `PRP.DEFERRED` status.** The coverage reconciliation rules are rewritten on lineage (`source_refs`), cross-type PRP → PD transformations are supported, input status changes are runtime-owned consequences, and hidden transformations are rejected.
5. **Repair budget 2 vs 1.** Everything is now 1 repair per call in the same conversation; `max_attempts` counts fresh conversations. The lint rejects any mismatch.
6. **Two hash methods.** `full_schema_hash` is now `sha256(JCS(schema))`, like every other hash.
7. **No way to reference an object created in the same response.** Added TempRef `{code, temp_id}`, resolved at commit, including QST effect targets.
8. **Implicit runtime-owned fields.** `runtime_injected_fields` is declared: `PRP.source_model` and `QST.session_id`.
9. **The stage 3 authority routing was prose.** It is now a deterministic Policy Engine: `authority_class` is required on PD; A0 closable, A1 → NEEDS_EVIDENCE, A2/A3 → OPEN + QST, A4 → DEFERRED. A DPL cannot widen A2/A3.

## Weak points fixed

- **Frame markers `<<<...>>>` could be stripped by markdown/HTML sanitizers.** Markers are now bare words located by their random tokens.
- **Rendered code blocks lose their fences and add chrome** such as "json" and "Copy code". Added the `SINGLE_BALANCED_JSON` mode plus lossless control-character escaping.
- **The monolith JSON duplicated the split files by hand.** It is now generated by `scripts/automation-spec-sync.js`; `--check` runs in jest.
- **Drifting duplicates in the bundle root were removed.** The root copy of the static runner crashed because it resolved the wrong root directory.
- **Fan-in commits atomically** only when `min_distinct_models` holds, and answers are persisted per model as they arrive, which makes the flow crash-safe.
- **Integration spec version and target were inconsistent** (2.2.0 vs 2.2.3; MyOrchestrator vs this repository).
