# Прогон

Всё, что относится к проведению живого прогона Basic в обычном Chrome: процедура, чек-лист, скрипты, шаблон отчёта. Исходные материалы каждого прогона (схема, итог, экспорт, заметки) лежат отдельно, в `docs/Run/Test_run/<имя>_<дата>/` (папка на прогон, подпапки `schema/`, `artefacts/`, `exports/`, `notes/`); вне этой папки материалов прогонов не держим.

Начинайте с [единого шаблона задания](run-brief-template.md): общий регламент в части 1, условия конкретного запуска в части 2. Заполните часть 2 и приложите модели этот файл и схему: он сам объявляет ей роль ведущего, а копию в `notes/run-brief.md` папки прогона ведущий сохраняет сам. Остальные документы — справочники по процедуре и инструментам; заполненный шаблон сохраняет правила, по которым проведён конкретный прогон.

| Файл | О чём |
|---|---|
| [run-brief-template.md](run-brief-template.md) | единое задание агенту: общий регламент и условия конкретного запуска |
| [Run Manual](<../Run Manual/README.md>) | ручной прогон без расширения: регламент, оркестрация вкладок, универсальная схема, режимы моделей |
| [run-organization.md](run-organization.md) | навигация к единому регламенту и справочникам без дублирования правил |
| [run-procedure.md](run-procedure.md) | процедура от подготовки до разбора, правила, что делать при окнах и сбоях |
| [run-report-template.md](run-report-template.md) | шаблон заметки о прогоне (`notes/run-report.md` в папке прогона) |
| `tools/` | скрипты (запуск JS во вкладке, проверка перед прогоном, импорт схемы, окна, карточки, версия) |

Связанные документы: [правила тестирования](../Agents/agent-live-test.md), [реестр проблем](../Agents/basic-issues-registry.md), [специфика платформ](<../Platform specifics/README.md>), [пособие по схемам](<../Scheme create/schema-craft-handbook.md>).

Запрет и разрешения владельца: новый прогон запускается только по явному разрешению владельца в чате на конкретную задачу (запрос моделям отправляется на их сайты). Чтение страницы без отправки запроса прогоном не считается.
