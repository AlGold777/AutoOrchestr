**Безопасное инженерное допущение:** реальных видео тренера и спортсменов нет (в документе — «не нашёл»), каталог ошибок не проверен тренером, числовых порогов нет. Поэтому проверка техники смэша ведётся по общепринятым биомеханическим ориентирам без утверждения конкретных углов; метки времени считаются демонстрационными и не валидированными. Для реального анализа принимаю, что ракурс «сбоку» достаточен только для части признаков, а для надёжной оценки разворота корпуса и положения мяча относительно корпуса потребуется второй ракурс или 3D-поза.

**Нумерованный список замечаний:**

1. **Раздел 4, каталог ошибок.** Каталог в целом не путает плоский смэш с виборой и бандехой, фазы и метки правдоподобны. Однако SM02 «Недостаточный разворот корпуса» в падел-смэше не всегда является ошибкой: в современном падел часто применяется открытая стойка для быстрого восстановления. Для базового плоского смэша разворот желателен, но формулировка «плечи почти не развёрнуты боком» может быть слишком категоричной. **Как исправить:** добавить оговорку «для базового плоского смэша; в игровых ситуациях допустима открытая стойка» или перевести SM02 в рекомендацию, а не ошибку. **Важность:** низкая.

2. **Раздел 4, метки времени.** Метки эталона ref-001 даны только для первого удара (до 00:03.2), хотя в эталоне 14 с и в попытках два удара. Это не ошибка техники, но неполнота демо-данных. **Как исправить:** добавить метки фаз для второго удара эталона или явно указать, что referenceMs для второго удара берётся из соответствующего прохода эталона. **Важность:** низкая.

Документ сам признаёт, что SM02, SM05, SM06 плохо различимы на одном 2D-ракурсе. **Как исправить:** в S05 для таких ошибок показывать не только скелет, но и текстовую пометку «условная демонстрация; ракурс сбоку ограничивает оценку» либо снижать визуальный акцент на суставах таза. **Важность:** средняя (для честности прототипа).
