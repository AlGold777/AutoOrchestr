# Независимый аудит «Проект прототипа v1»

Инженерные допущения: проверяется проектная документация, не работающий HTML. Исходный код, видеофайлы и реализация экранов отсутствуют — не нашёл. Демонстрационная имитация допустима, но должна быть явно отделена от реального анализа записанного видео. Приоритет оценки — выполнение сквозного сценария владельца.

Общий вердикт: проект имеет работоспособную концепцию, но пока не готов к реализации без уточнений. Обнаружено 5 блокирующих, 5 высокоприоритетных и 3 среднеприоритетных замечания.

## Замечания

1\. Новая запись спортсмена не получает разбор.\
Где: §§2, 3 (S03–S05), 5, 6.\
Проблема: MockProvider возвращает анализ только для `attempt-001/002`. Новая запись получает другой ID и заканчивается сообщением «Нет демо-данных». Главный сценарий фактически не замкнут.\
Исправление: после сохранения новой записи разрешить выбор демонстрационного сценария 1/2. Сохранить `mockScenarioId` отдельно от `attemptId`. Показывать результат с предупреждением, что ошибки не вычислены по записи.\
Важность: блокирующая.

2\. Не определены переходы после отказа камеры.\
Где: §§2–3, S02.\
Проблема: импорт файла и выбор демо упомянуты, но их маршруты и конечные состояния отсутствуют.\
Исправление: формализовать `S02 → импорт → S03` и `S02 → выбор демо → S05`, включая отмену импорта.\
Важность: высокая.

3\. Не определена обработка неустранимой ошибки анализа.\
Где: S04.\
Проблема: предусмотрен повтор S04, но не описан выход при повторной ошибке, кроме общей отмены.\
Исправление: добавить явные действия «Назад к попыткам», «Повторить анализ», «Открыть демо-разбор».\
Важность: средняя.

4\. Замена эталона не обеспечена моделью данных.\
Где: §§3, 5.\
Проблема: JSON содержит один `reference`, хотя старые попытки должны сохранять привязку к предыдущим эталонам.\
Исправление: использовать `references[]`, `activeReferenceId`; сохранять версии эталонов и ссылки попыток.\
Важность: блокирующая.

5\. Экран результата не гарантирует кадр с наложенной разметкой.\
Где: S05, §5.\
Проблема: предусмотрены SVG-позы, но не определены изображения-подложки. Получится сравнение схем, а не размеченных кадров.\
Исправление: добавить `athleteFrameAsset`, `referenceFrameAsset` и SVG-слой поверх каждого изображения.\
Важность: блокирующая.

6\. Неполная привязка ударов эталона.\
Где: §5.\
Проблема: `shotIndex` обозначает удар спортсмена, но соответствующий удар тренера не указан.\
Исправление: добавить `referenceShotIndex`; валидировать фазу и временные метки обеих записей.\
Важность: высокая.

7\. Не завершён контракт анализа.\
Где: §6.\
Проблема: описан `Promise<AnalysisResult>`, однако фактический JSON содержит вложенное `analysis`. Не определены обязательные поля, ошибки и состояния провайдера.\
Исправление: утвердить единую JSON Schema для `AnalysisResult`, включая `status`, `errors`, `qualityWarnings` и типы evidence.\
Важность: блокирующая.

8\. Недостаточен контракт графической разметки.\
Где: §§5–6.\
Проблема: указаны координаты ключевых точек, но отсутствуют размеры исходных кадров, преобразования координат и правила масштабирования.\
Исправление: добавить размеры кадра, ориентацию, систему координат и преобразование в область отображения.\
Важность: высокая.

9\. Противоречие в размещении каталога.\
Где: §§5, 7.\
Проблема: каталог назван `catalog.json`, но в файловом плане присутствует только `data.js`.\
Исправление: разместить каталог внутри `window.DEMO_DATA.catalog` либо добавить отдельный подключаемый файл.\
Важность: средняя.

10\. Не обеспечена согласованность сохранённых данных.\
Где: §§3, 7.\
Проблема: видео хранится в IndexedDB, метаданные — в localStorage. Возможны осиротевшие записи после ошибки или очистки хранилища.\
Исправление: хранить видео и метаданные в IndexedDB, предусмотреть восстановление незавершённого сохранения.\
Важность: высокая.

11\. Режимы запуска смешаны.\
Где: допущение 8, §7.\
Проблема: офлайн-просмотр через `file://` и работа камеры имеют разные ограничения безопасности.\
Исправление: зафиксировать HTTPS как основной режим; офлайн-съёмку считать отдельной проверяемой функцией.\
Важность: высокая.

12\. Проверка совместимости недостаточна.\
Где: §§7–8.\
Проблема: не определены испытания Safari iOS на доступность камеры, поддержку MIME, завершение MediaRecorder и воспроизведение.\
Исправление: добавить матрицу браузеров и тесты отказов каждого этапа записи.\
Важность: средняя.

13\. Приёмка не проверяет главное исправление.\
Где: §8.\
Проблема: AC06–07 проверяют только заранее созданные попытки, но не сценарий новой записи с последующим демонстрационным разбором.\
Исправление: добавить AC19: новая запись → сохранение → выбор демо-сценария → S05 с корректными метками и предупреждением об имитации. Также проверить замену эталона и сохранность истории.\
Важность: блокирующая.
