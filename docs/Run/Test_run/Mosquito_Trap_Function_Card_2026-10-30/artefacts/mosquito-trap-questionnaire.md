# Опросник функций ловушки для комаров (энтомологический мониторинг)

Как пользоваться: в каждой группе отметьте нужные варианты (заменив ☐ на ☒). У каждого варианта — чем отличается, источник и статус: «подтверждено» — есть официальная документация или два независимых источника; «не подтверждено» — нет проверяемого источника, ссылка общая или заявка вендора без независимой проверки. Источники: 2025–2026 годы, где указано иное — год в тексте. Статусы исправлены по независимой проверке (GPT, Perplexity).

Перед выбором определите научную задачу, измеряемую величину, эталон сравнения и протокол валидации (группа 14); затем — приманки, сбор, ИИ и электронику.

## Совместимость и конфликты вариантов

Один основной источник CO₂ (выбрать одно из 2.1, 2.2, 2.3); 2.1 требует 5.7 и 7.x для электроклапана.

Исключают друг друга или ограничивают выбор:
- 3.1 (живой сбор) исключает 3.6 (утопление в жидкости) и снижает ценность 3.2 (клей портит образцы для вирусологии); 3.2 — для подсчёта и морфологии.
- 4.1 (этанол, RNAlater) исключает выделение живого вируса; для вируса и RT-PCR обязательны 4.6 и желательно 4.3. Свою цель образцов (морфология, ДНК, РНК, живой вирус) выберите до выбора группы 4.
- 4.4 и 4.5 работают только вместе с каруселью 3.4; 3.4 — экспериментальный модуль.
- 7.2 (6/12 В свинцово-кислотный или Li-Ion) несовместим с круглосуточной камерой и ИИ (5.3, 5.4, 6.x): для них нужен 7.1 или 7.5. Считайте энергобюджет по формуле Вт·ч ÷ часы, а не по заявленной автономности.
- 13.1 (DIY) и 13.3 (премиум) — один из двух; 13.2 совместим с любой из ловушек группы 1 без ИИ.

Требуют друг друга:
- 5.1 → пролётный канал (3.3 или конструкция BG-Counter 2); 5.1 только считает, вид не определяет.
- 6.1 → 5.3; 6.2 → 5.4; 6.3 → 5.2; 6.4 → 5.3 или 5.4 и 8.1 или 8.2; 6.7 → 6.1 или 6.2.
- 5.5 (подогрев окна) → 5.3 или 5.4; повышает расход энергии (бюджет 7.1).
- 8.1, 8.2, 8.3 → 9.1; 9.2 (OTA) и 9.4 (удалённая конфигурация) → любая связь 8.1–8.3; без связи используйте 8.5 (BLE) и 9.3.
