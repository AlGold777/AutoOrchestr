## Формулировки, которые сбивают с толку
1. «копия неполная» читается как «ответ неполный», хотя относится к копии и стоит и на принятых ответах.
2. «uncompleted», «Extract failed», «Result: Error», «Double-click to fetch» — английский в русском интерфейсе.
3. Один участник одновременно: окно «пустой», карточка «Extract failed».
4. «Повторить» не значит «взять готовый ответ»: по телеметрии это новая отправка (в 2.81.952 заявлено обратное, M-18).
5. В окнах решения нет «Ожидает с …» (есть только у «Ответ User»).
