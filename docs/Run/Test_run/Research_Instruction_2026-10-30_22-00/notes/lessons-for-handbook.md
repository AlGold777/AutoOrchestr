# Уроки для пособия по схемам (прогон «Исследование инструкция v2»)

- Задание шага после шага User не должно требовать то, что User мог убрать: r5 требовал «инструкция + три пункта», User убрал пункты, модель вернула их снова. Если User что-то правит, итоговое задание должно говорить «сохрани правки User, даже если они убирают ожидаемую часть».
- Согласуй лимиты слов: `run.maxWords` (1000) противоречил заданию (1200); лимит в схеме и в тексте задачи должен быть один.
- «Слов: N» в конце ответа конфликтует с меткой доставки; модель не считает слова точно (заявлено 1193, фактически 1186): не проси точных чисел, которые приложение не проверяет.
- Не ставь `role` критического аудита участнику, которому поручен поиск практик: роль добавляет текст «Проведи экспертный аудит…» и сдвигает ответ.
- Необязательный участник, выбывший в r1, стоит раунду 21 минуту ожидания (автопропуска нет): опорные модели ставь отдельным раундом, а необязательных не сопровождай «Повторить».
- Шаг User «ответь на вопросы из раздела…» не должен ссылаться на раздел, которого в документе нет (вопросы лежали после `[[/DOC]]`).
