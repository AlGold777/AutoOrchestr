## Найдено в прогоне (новое)

1. **Таблицы теряют разделители** в итоговом документе (1 символ `|` на весь файл): извлечение текста страницы отдаёт текст без таблиц. Известно с первого прогона (A13 ревью). Нужно проверить извлечение разметки провайдера Claude (`shared/answer-markdown-providers.js`).
2. **Маркеры `[[DOC: …]]` / `[[/DOC]]` остаются в сохранённом артефакте** (2 вхождения): срез работает для текста, идущего дальше, но не для документа, сохраняемого в `artefacts`.
3. **Perplexity непригоден как проверяющий на этой странице**: оба ответа — эхо запроса. Его вклад в схему нулевой; по правилу тестирования исключён пропуском участника. Решение для схемы: заменить на другую модель или сделать необязательным (в v2 вход Perplexity уже `required: false`).
4. Окно решения неполного раунда не находилось моим скриптом по `.choice-dialog` (это `#confirm-modal`, другая разметка окна) — для следующих прогонов проверять оба типа окон.
