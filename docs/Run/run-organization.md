# Организация прогонов Basic

Единый источник регламента и задания агенту — [run-brief-template.md](run-brief-template.md).

- Часть 1 шаблона описывает роли, подготовку, наблюдение, обработку окон и сбоев, фиксацию и закрытие находок, сохранение результатов и разбор.
- Часть 2 содержит условия конкретного запуска. Заполненный документ хранится в `notes/run-brief.md` папки соответствующего прогона в `docs/Run/Test_run/`; сведения о «ближайшем прогоне» сюда не добавляются.

Технические справочники:

- [run-procedure.md](run-procedure.md) — команды подготовки, импорта и экспорта; порядок работы задаёт единое задание.
- [model-modes.md](model-modes.md) — состав участников и режимы сайтов моделей.
- [run-report-template.md](run-report-template.md) — форма отчёта.
- [agent-live-test.md](../Agents/agent-live-test.md) — подробности окон и среды.
- [basic-issues-registry.md](../Agents/basic-issues-registry.md) — единый реестр проблем.
- [Специфика платформ](<../Platform specifics/README.md>) — наблюдения по среде и провайдерам.

Все материалы конкретного прогона размещаются по правилам единого задания. Порядок работы с версией, git и субагентами задаёт корневой [AGENTS.md](../../AGENTS.md).
