# Automation

Страница `automation_lab.html` (колба в панели Pipeline) — стадии 1–5 Product→Architecture.

1. Выберите 2–4 модели. Первая — **модератор**: ведёт стадии 1, 3, 4. На стадиях 2 и 5 отвечают все модели параллельно.
2. Введите идею → **Send**.
3. Отвечайте на вопросы в центре: правила решений (после стадии 1) и варианты решений (после стадии 3).
4. **Results** — итог, **Save** — .md, **Cancel** — сброс.

Состояние живёт до перезагрузки страницы. ⚙ — диагностика и «Отчёт для Claude»; то же — в окне телеметрии, вкладка Automation. **Симулятор** — прогон без веб-моделей.
