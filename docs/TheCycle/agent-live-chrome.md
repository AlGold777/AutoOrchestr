# Живой Chrome: как управлять страницами и моделями

Для агентов, которые ведут живой прогон (Circle, Basic) в обычном Chrome пользователя. Всё проверено на P7 (2026-11-28).

## Главное
- **Не опрашивать вхолостую.** Ждать цикл с условием, не слать «посмотри ещё раз» каждые 20 секунд.
- **Конец ответа** = метка `[[AO-…]]` последней строкой + кнопка «Копировать»/«Copy» + нет «Стоп». Если вместо этого стоит **«Continue»** (DeepSeek) — ответ оборван, его надо продолжить.
- **Быстрые модели** (Gemini Авто, GPT Instant, DeepSeek без DeepThink): до 5 минут без смены статуса — норма.
- **Если сбор не идёт — найти причину и чинить самому** (код, телеметрия, DOM вкладки). Пользователь это одобрил.
- Расширение перезагружать только после доставки правки кода. Перезагрузка закрывает его вкладки и сбрасывает пресет, схему, модели, лимит, задачу.

## Инструменты (`scripts/agent/`)
| Скрипт | Что делает |
|---|---|
| `tab-js.sh <часть URL> <файл.js>` | выполнить JS во вкладке (Apple Events). Расширение-страницы: `window.TheCycle*` и `chrome.*` недоступны, DOM виден |
| `tab-click.sh <часть URL> '<css>'` или `--text Continue` | **настоящий клик** (CGEvent). `HIT` — нажато, `MISS` — элемент перекрыт (модальное окно), `NOEL` — нет элемента |
| `ext-reload.sh` | перезагрузить расширение без кликов |

## Нажатие кнопок
- JS `click()` страница (DeepSeek, Gemini) **игнорирует**. Нужен настоящий клик: `tab-click.sh 0fa9213b --text Continue`.
- Часть URL берите из адреса именно нужной вкладки: вкладок Gemini/DeepSeek бывает несколько (старые + текущий прогон). Узнать адреса: `osascript -e 'tell application "Google Chrome" to get URL of every tab of every window'`. Вкладка прогона — самая новая; у неё последняя метка `[[AO-…]]` совпадает с запросом.
- Приложение Claude забирает фокус при каждой команде. `tab-click.sh` сам делает вкладку активной и Chrome — передним. Для скриншота добавляйте в той же команде `osascript -e 'tell application "Google Chrome" to activate' -e 'delay 1.2'`. Результат проверяйте JS-запросом, не скриншотом.
- Координаты в скриншотах: пиксели ×0.584 = точки экрана.

## «Continue» у DeepSeek
1. Признак: в `div[role=button]` есть текст «Continue».
2. Нажать `tab-click.sh <url чата> --text Continue`, подождать, пока текст перестанет расти (3 замера подряд), повторить, если «Continue» появилась снова.
3. Конец — метка `[[AO-…]]` и нет «Continue».
Код адаптера (`content-scripts/content-deepseek.js`, 2.81.1163) дописывает такой ответ сам; если не сработало, нажмите вручную по шагам выше.

## Панель pipeline_panel
- Пресет выбирается радиокнопкой в списке «Pipelines» (клик по кружку, не по названию). После выбора Circle появляется блок «Схема цикла».
- Запуск — кнопка ▶ на холсте (`#debate-run-toggle-btn`), а не скрытая «Start Circle». Повторный ▶ во время прогона = стоп.
- «Pipeline already running» при «Продолжить» значит: страница ещё держит прежний прогон. Остановить (▶ ещё раз), закрыть окно OK, затем «Продолжить».
- **Любое модальное окно закрывать сразу** (`OK`) — оно перекрывает клики (`MISS`) и может висеть часами.
- Статус надёжнее читать кнопкой `#circle-status` (JSON с фазой, циклом, расходом), чем строкой статуса: она может застрять на «подготовка запуска».

## Пока идёт прогон
- Режимы моделей: Gemini «Авто» (вручную), GPT Instant, DeepSeek без DeepThink (ставит `platform-mode-setter.js`).
- Включить «New pages», чтобы расширение не писало в чаты пользователя.
- Рабочий чат с GPT-архитектором (`scripts/agent/gpt-*.sh`) в прогон не вмешивать.
