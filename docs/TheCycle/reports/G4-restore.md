# Этап «Восстановление из резервной копии (G4.3)», 27.11.2026, версия 2.81.1152

Задание GPT (оппонент): подключить существующее восстановление к интерфейсу TheCycle. Реализовал Claude.

## ГИПОТЕЗА

**Подтверждена тестами и живой приёмкой.** Восстановление собрано из существующих компонентов; Basic Engine не менялся. G4.3 закрыт.

## ДАННЫЕ

- Страница «TheCycle — резервирование»: выбрать копию → «Восстановить». Дальше без вопросов: проверка копии → проверка, что отправок нет → новая база → перечитка записанного → включение → список исследований в Circle.
- Отказ, при котором активная база не меняется: повреждённая или несовместимая копия, идущее или только что прерванное исследование, пустая копия, копия без части локальных данных.
- Прежняя база не удаляется.
- C-13: «Закрыть исследование» пишет проверенную копию закрытого состояния.
- Независимая проверка первой реализации нашла 3 дефекта, все исправлены (2.81.1152) и проверены повторно:
  - старая копия заменяла более полные локальные данные;
  - на чистом устройстве терялся текст своей роли;
  - предупреждение о неизвестном исходе показывалось без такого запроса.
- Тесты: jest — 482 пройдено, 11 пропущено; TheCycle — 257 пройдено. Сценарии — `tests/thecycle-restore-resume.test.js`, `tests/thecycle-adapter-failures.test.js`.

## ВЛИЯНИЕ НА ПЛАН

- Пункт G4 «восстановление из копии» закрыт.
- Возвращается состояние на момент копии: запросы, отправленные после неё, в ней не записаны.
- Вернуться на прежнюю базу из интерфейса нельзя.
- Копия, в которой нет части локальных данных, не восстанавливается.
- Новая мелочь: C-14 в реестре.

## НЕ ПРОВЕРЕНО

- Чистый профиль браузера. Отсутствие локальных данных имитировано пустой активной базой: `chrome.storage` и отметки о копиях не очищались. Чистое хранилище покрыто тестом.
- Подтверждение ответа со страницы модели после восстановления: прерванный запрос остался в поле ввода и не ушёл.
- Перезагрузка расширения во время запроса и схема из нескольких раундов (общая приёмка G4/G5).
