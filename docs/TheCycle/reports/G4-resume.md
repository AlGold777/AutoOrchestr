# Этап «Универсальное возобновление исследования (G4.2)», 27.11.2026, версия 2.81.1151

Задание GPT (оппонент): Stop — приостановка, а не закрытие. Реализовал Claude.

## ГИПОТЕЗА

**Подтверждена тестами и живой проверкой.** Возобновление сделано на существующих механизмах TheCycle; Basic Engine не менялся.

## ДАННЫЕ

- Stop: пауза, владение транспортом снято; незавершённая отправка остаётся `UNKNOWN`.
- «Продолжить»: тот же `researchId`, нумерация циклов и `usedCalls` сохраняются; отложенный шаг выполняется по записанному пакету, прежнее решение уходит в `decisionHistory`.
- Лимит только увеличивается, история — `budgetHistory`.
- Выбор любого сохранённого исследования в интерфейсе.
- Явное «Закрыть» и `COMPLETE` окончательны.
- Независимая проверка первой реализации нашла 6 дефектов, все исправлены и закрыты тестами `tests/thecycle-resume-recovery.test.js`:
  - исследование не продолжалось после цикла без пригодных ответов;
  - подтверждённый перечиткой ответ выбрасывался и оплачивался повторно;
  - проверенное решение терялось после прерванного шага аналитика;
  - перезагрузка после записанного ответа переотправляла шаг;
  - лимит на цикл сохранялся даже при отказе увеличить бюджет;
  - второй Stop мог оставить транспорт занятым.
- Отчёт прерванного цикла собирается повторным проходом Basic по записанным ответам, без отправки; прежние записи не меняются (`RECOVERED_RESULT`).

Проверка GPT коммита 2.81.1147 (R01–R03), все три замечания подтвердились по коду и исправлены в 2.81.1148:

- R01: схема и параметры не входили в файловую копию — теперь лежат в состоянии исследования.
- R02: после Stop копии не было — теперь есть, прерванный запуск включён; сбой копии паузу не отменяет, «Продолжить» сначала делает проверенную копию.
- R03: бюджет и лимит на цикл писались раздельно — лимит на цикл теперь выводится из бюджета.

Проверка GPT 2.81.1148: восстановление из копии при утрате всех локальных данных. Сквозной тест подтвердил дефект: «Продолжить» упирался в `BACKUP_REQUIRED`, потому что отметки о проверенных копиях пропадают вместе с хранилищем. Исправлено в 2.81.1149.

Сквозной тест `tests/thecycle-restore-resume.test.js` (пустая база, пустое хранилище страницы, копия из каталога):

- приостановленное исследование продолжается до `COMPLETED`, записанные ответы не переотправляются;
- исследование, остановленное во время отправки, ждёт выбора человека; после «отбросить» и «Продолжить» доходит до `COMPLETED`.

## ВЛИЯНИЕ НА ПЛАН

- В интерфейсе восстановить из копии нельзя: страница копий только создаёт и проверяет (`canActivate: false`), `recovery-runtime.js` и `activation-coordinator.js` ни одной страницей не подключены. Для пункта G4 «восстановление» это открыто.
- Живые проверки G4 из плана выполнять по новому поведению Stop.
- Исследования, закрытые прежними версиями по Stop, не продолжаются.

- Местное время в списке (2.81.1151) — только тест.
