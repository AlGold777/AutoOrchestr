# Этап «Универсальное возобновление исследования (G4.2)», 27.11.2026, версия 2.81.1147

Задание GPT (оппонент): Stop — приостановка, а не закрытие. Реализовал Claude.

## ГИПОТЕЗА

**Подтверждена тестами.** Возобновление сделано на существующих механизмах TheCycle; Basic Engine не менялся.

## ДАННЫЕ

- Stop: пауза, владение транспортом снято; незавершённая отправка остаётся `UNKNOWN`.
- «Продолжить»: тот же `researchId`, нумерация циклов и `usedCalls` сохраняются; отложенный шаг выполняется по записанному пакету, прежнее решение уходит в `decisionHistory`.
- Лимит только увеличивается, история — `budgetHistory`.
- Выбор любого сохранённого исследования в интерфейсе.
- Явное «Закрыть» и `COMPLETE` окончательны.
- Независимая проверка первой реализации нашла 6 дефектов, все исправлены и закрыты тестами `tests/thecycle-resume-recovery.test.js`:
  - исследование не продолжалось после цикла без пригодных ответов;
  - подтверждённый перечиткой ответ выбрасывался и оплачивался повторно;
  - проверенное решение терялось после прерванного шага аналитика;
  - перезагрузка после записанного ответа переотправляла шаг;
  - лимит на цикл сохранялся даже при отказе увеличить бюджет;
  - второй Stop мог оставить транспорт занятым.
- Отчёт прерванного цикла собирается повторным проходом Basic по записанным ответам, без отправки; прежние записи не меняются (`RECOVERED_RESULT`).

## ВЛИЯНИЕ НА ПЛАН

- Живые проверки G4 из плана выполнять по новому поведению Stop.
- Исследования, закрытые прежними версиями по Stop, не продолжаются.

## НЕ ПРОВЕРЕНО

- Всё живьём в Chrome.
- Исправления повторно независимой проверке не отдавались.
- Цикл, где часть шагов схемы не выполнялась, не достраивается: он пропускается и не идёт в доказательства.
