Реши конечную задачу дискретной оптимизации.
Данные полные. Внешние источники не нужны.
Не выполняй программный код и не используй вычислительные
инструменты, калькуляторы, внешние сервисы или поиск.
Выполняй расчёты посредством собственных рассуждений.
Разрешается написать алгоритм или программный код
для доказательства воспроизводимости решения,
но запрещается исполнять его в ходе исследования.
Если точное значение не установлено, укажи null.
Не выдавай предположения за результаты вычислений.

ЗАДАЧА 1. ОБЫЧНАЯ ОПТИМИЗАЦИЯ
Определи количество всех допустимых наборов.
Найди три лучших допустимых набора.
Порядок сравнения:
1. Максимальная ценность.
2. При равенстве — меньшая стоимость.
3. При равенстве — лексикографически меньшая строка ID.
Для каждого набора укажи отсортированные ID,
стоимость, ценность и непокрытые элементы.
ЗАДАЧА 2. РОБАСТНАЯ ОПТИМИЗАЦИЯ
Для каждого допустимого набора рассмотри пять
сценариев отказа: удаление одного выбранного проекта.
Робастность набора — минимальная ценность покрытия
среди этих пяти сценариев.
Ограничения допустимости проверяются только
для исходного набора из пяти проектов.
Порядок сравнения:
1. Максимальная робастность.
2. Максимальная исходная ценность.
3. Минимальная исходная стоимость.
4. Лексикографически меньшая строка ID.
Найди глобальный робастный оптимум.
Укажи его ID, стоимость, исходную ценность,
worst-case и ценность после каждого из пяти отказов.
ЗАДАЧА 3. ВОСПРОИЗВОДИМОСТЬ
Представь точный алгоритм проверки всех результатов.
Разрешается использовать ручную декомпозицию,
комбинаторный подсчёт, верхние и нижние границы,
исключение заведомо неоптимальных вариантов.
Отдельно обозначай:
- проверенные результаты;
- кандидатов, требующих проверки;
- установленные границы;
- нерешённые вопросы.
Не заменяй ранее проверенный корректный результат
на null без конкретного основания считать его ошибочным.
Однако не объявляй проверенного кандидата глобальным
оптимумом без достаточных оснований.
