Реши конечную задачу дискретной оптимизации.

Данные полные. Внешние источники не нужны.
Не выполняй программный код и не используй вычислительные
инструменты, калькуляторы, внешние сервисы или поиск.
Выполняй расчёты посредством собственных рассуждений.
Разрешается написать алгоритм или программный код
для доказательства воспроизводимости решения,
но запрещается исполнять его в ходе исследования.
Если точное значение не установлено, укажи null.
Не выдавай предположения за результаты вычислений.

Нужно выбрать ровно 5 из 12 проектов A–L.

ЗАДАЧА 1.

Найди три лучших допустимых набора по ценности.

Порядок сравнения:
- максимальная ценность;
- при равенстве меньшая стоимость;
- затем лексикографически меньшая строка ID.

Для каждого набора укажи:
- отсортированные ID;
- суммарную стоимость;
- ценность;
- непокрытые элементы.

Укажи количество всех допустимых наборов.

ЗАДАЧА 2.

Найди робастный оптимум: максимизируй минимальную
ценность покрытия после отказа любого одного
из пяти выбранных проектов.

Ограничения проверяются на исходном наборе
из пяти проектов, а не на оставшихся четырёх.

Порядок сравнения:
- максимальная минимальная ценность после отказа;
- максимальная исходная ценность;
- меньшая стоимость;
- лексикографически меньший набор.

Укажи ID, стоимость, исходную ценность,
worst-case и значения после отказа каждого
из пяти выбранных проектов.

ЗАДАЧА 3.

Дай воспроизводимый алгоритм точной проверки,
включая фильтры допустимости, вычисление покрытия,
проверку всех отказов и порядок сравнения.

Не смешивай доказанные результаты и гипотезы.
Не изобретай результаты выполненных вычислений.

Итоговые численные результаты представь
в отдельном JSON-блоке следующей структуры:

{
  "feasible_count": null,
  "top3": [
    {
      "ids": null,
      "cost": null,
      "value": null,
      "uncovered": null
    }
  ],
  "robust_optimum": {
    "ids": null,
    "cost": null,
    "value": null,
    "worst": null,
    "after_failure": {}
  }
}

Массив top3 должен содержать три объекта.
Непокрытые элементы — массив целых чисел.
after_failure — объект, в котором ключи являются
ID отказавших проектов, а значения — ценностью
оставшегося покрытия.

Если значение не установлено, используй null.
Не подменяй неизвестные значения догадками.

Помимо JSON представь алгоритм, обоснование,
установленные результаты, спорные выводы
и открытые вопросы.
