# Архитектор (GPT, чат)

Главный архитектор. Даёт задание этапа и решает спорное. Владелец в работе не участвует.

- Оператор отправляет ему отчёт формата СДЕЛАНО / НУЖНО ОТ GPT / БЛОКЕР (`scripts/agent/gpt-send.sh`) и читает ответ (`gpt-last.js`). Сторож пишет в ALERT `GPT_REPLY`, когда ответ готов.
- Спорные решения (изменение Basic Engine, смена критериев) — только через него: оператор формулирует решение и основание, просит «ВОЗРАЖЕНИЕ: …» или «СОГЛАСЕН».
- Адрес чата в репозиторий, коммиты и отчёты не попадает.
