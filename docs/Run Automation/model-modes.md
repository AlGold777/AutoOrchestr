# Режимы моделей для прогона

Единый источник: какие режимы сайтов моделей должны быть выставлены перед прогоном. Значения даёт владелец; пустые строки — «не указано владельцем», их не домысливать: спросить.

| Модель | Участие в прогоне | Режимы |
|---|---|---|---|
| GPT (ChatGPT) | участвует (опорная модель) | уровень рассуждений **High** |
| Claude | участвует (автор свода, правки, итога) | модель **Sonnet 5.5** |
| DeepSeek | участвует (отвечает быстро, инженер) | режим **DeepThink ВКЛЮЧЁН**, **поиск ВЫКЛЮЧЕН** |
| Qwen | участвует как инженер на сложных этапах, необязательный | модель **Qwen4-Max** (до 2026-11-25 называлась Qwen4-Max-Preview), режим **Мышление** |
| Perplexity | участвует как инженер на сложных этапах, необязательный | выбранная модель **Kimi (версия 3, режим размышления)** внутри Perplexity; поиск Perplexity — по умолчанию |
| Mistral (Le Chat) | разрешена | режим **Think** |
| Z.ai | разрешена | модель **GLM-5.3** (не Flash) |
| Grok | разрешена | режим **Build** |
| Gemini | основным участником НЕ использовать; разрешена как независимый проверяющий в Circle (VERIFY) — отвечает быстро (владелец, 2026-11-27) | — |
| Kimi (сайт Kimi.ai) | НЕ использовать как отдельного участника: Kimi задействован только как модель внутри Perplexity; вкладка kimi.ai в нашей системе вставляется в Perplexity и открывается на `kimi.ai/make3d` (реестр M-15) | — |

В Basic и Circle расширение выставляет эти режимы само перед каждой отправкой и сверяет их по странице (`content-scripts/platform-mode-setter.js`). Фактический режим лежит в телеметрии прогона, событие `PLATFORM_MODE`. Не удалось выставить — запрос не уходит, участник выбывает по обычному правилу. При ручном прогоне: `tab.sh <вкладка> ensure`, затем `tab.sh <вкладка> ensured`.
