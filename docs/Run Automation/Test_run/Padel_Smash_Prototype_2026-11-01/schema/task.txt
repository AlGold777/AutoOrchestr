Сделай проект прототипа мобильного приложения для падел-тренировок.

Сценарий: спортсмен снимает свой подход (серию ударов) на телефон и сохраняет видео; приложение сравнивает его движения с эталоном тренера и показывает найденные ошибки с советом.

Решения владельца (не пересматривать):
1. Прототип — кликабельный HTML (экраны открываются в браузере и на телефоне), данные заготовлены заранее.
2. Сравнение с эталоном в прототипе — имитация на заготовках: ошибки и советы заранее прописаны для демонстрационных видео, настоящего анализа позы нет. Но проект должен показать, как настоящий анализ будет встроен позже.
3. Упражнение — смэш в падел (верхняя подача на отбой).
4. Эталон записывает тренер в том же приложении: один и тот же экран съёмки работает в ролях «тренер» и «спортсмен».
5. Результат для спортсмена — список ошибок с советами и кадр с разметкой (скелет спортсмена рядом с эталоном, метка времени, короткий совет).

Результат — «Проект прототипа»: сквозной сценарий и список экранов с переходами; содержимое каждого экрана; каталог типичных ошибок смэша в падел (по 6–8 ошибок: признак на видео, что не так, как исправить, совет одной фразой); заготовленные демонстрационные данные (формат JSON и пример по двум попыткам); описание, как позже заменить имитацию настоящим анализом позы; план сборки HTML-прототипа; критерии приёмки.
