Проект прототипа «Padel Smash Coach»

Допущения: статичная камера сбоку в 2–3 м, 60 к/с, один удар в ролике; оценка только техники (без трекинга мяча); прототип хранит всё в одном HTML с data.js.

Сравнение движений с эталоном

Подход: экстракция 33 ключевых точек позы на кадр, нормализация по bounding box, перевод точек в углы суставов, выравнивание попытки и эталона по фазам через DTW (компенсирует разную скорость), сравнение углов в ключевых фазах. Для телефона лучше всего подходит MediaPipe Pose Landmarker: 33 3D-лендмарка, работает на Web/Android/iOS офлайн, режимы IMAGE/VIDEO/LIVE_STREAM. MoveNet легче, но без z-координат и устарел; Apple Vision — только iOS, запирает разработку. Фазирование смэша: стойка-профиль → замах (касание лопаты) → разгиб → удар → проводка — ключевые кадры определяются по экстремумам углов локтя и плеча.

Замена имитации анализом

Заготовка уже хранит финальный формат: ключевые кадры, углы, ошибки — экраны S7/S8 его не меняют. Заменяется только продюсер JSON: модуль analysis.js получает видео, гонит MediaPipe Pose Landmarker по кадрам, нормализует точки по bounding box, считает углы суставов, выравнивает с эталоном через DTW, детектирует фазы по экстремумам угла локтя, сопоставляет отклонения углов с порогами каталога ошибок. Интерфейс: analyze(videoBlob, refId) → Promise<AttemptJSON> — переключение заглушка/реал одной строкой конфигурации.

План сборки HTML

index.html + data.js (JSON выше), mobile-first 390×844, CSS flexbox.

Экраны — <section>, навигация hash-router (#s4), переходы кнопками.

S4: MediaDevices getUserMedia с фолбэком на статичный постер; запись не обязательна — кнопка «Использовать демо».

S8: Canvas/SVG поверх кадра, два скелета из точек JSON, таймкод.

S6: таймер 2 с → S7. Сборка: один день, без бэкенда.

Критерии приёмки

Полный проход S1→S8 за ≤2 мин в Chrome desktop и Safari iOS.

Съёмка идентична в обеих ролях, отличается только лейбл.

Отчёт показывает ≥2 ошибки с советом из каталога; таймкод кликабелен.

JSON демо заменяем без правки экранов.
