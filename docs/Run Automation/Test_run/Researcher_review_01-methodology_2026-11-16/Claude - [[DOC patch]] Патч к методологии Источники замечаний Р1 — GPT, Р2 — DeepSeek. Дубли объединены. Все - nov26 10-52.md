# Патч к методологии

Источники замечаний: Р1 — GPT, Р2 — DeepSeek. Дубли объединены. Все правки ужесточают ядро (запрет менять критерии, предсказание до проверки, слепая проверка). Ничего не смягчено, числа не вводятся.

## Принято

**П1 (Р1-1). §2, Г3.**

- Было: «сравнением с плацебо»; в таблице «плацебо той же цены».
- Стало: «Плацебо — перестройка той же цены и класса, без записи диагноза. Её выбирает жребий из реестра до запуска испытуемой перестройки. Автор перестройки в выборе не участвует. Выбор пишется в журнал до исхода».
- Отказ: контроль подобран слабым под нужный исход \[И: нынешний текст не ограничивает выбор\].
- Проверка \[Г\]: двое испытателей берут плацебо из одного реестра, и оба получают допустимое множество. Выбор с отметкой времени позже исхода сверкой журнала отвергается.

**П2 (Р1-2). §3, таблица, «Доля подтвердившихся предсказаний».**

- Было: «прежняя конфигурация того же исхода не даёт».
- Стало: «Метка "рискованное" ставится по повторным запускам прежней конфигурации на том же случае. Число запусков назначает Э2 по разбросу пилота. Один успех прежней конфигурации снимает метку».
- Отказ: единичная удача перестройки засчитана как преимущество \[И\].
- Проверка \[Г\]: перестройка, у которой прежняя конфигурация успешна с известной ненулевой вероятностью. Доля засчитанных «рискованных» должна падать с ростом числа запусков.

**П3 (Р1-4, Р2-1). §3, переход ведущей валюты.**

- Было: «с цикла N ведущая валюта — В1, потому что …».
- Стало: «Ведущая валюта берётся из диагноза по таблице §4. Переход допустим только при смене диагноза, записанной до цикла N и заверенной судьёй, не координатором. Прежняя ведущая валюта остаётся в сводке. Сам переход прогрессом не считается».
- Отказ: застой скрыт заменой показателя успеха. Это нарушает запрет менять критерии \[И\].
- Проверка \[Г\]: реплей журнала. Переход без записи смены диагноза — флаг. На синтетическом застое В2 при росте В1 отчёт показывает застой В2.

**П4 (Р1-5). §3, таблица, В1.**

- Было: «число отсечённых кандидатов текущего пула».
- Стало: добавить «Пул фиксируется отпечатком в журнале до применения правила и формируется не автором правила. Кандидат, отсекаемый детерминированным фильтром до заявки (§6), в В1 не входит».
- Отказ: В1 растёт от искусственного наполнения пула \[И\].
- Проверка \[Г\]: добавить в пул 1000 заведомо негодных кандидатов. В1 не должен вырасти.

**П5 (Р1-6, Р2-7). §4, диагностика и «массовая гибель».**

- Было: «несколько конкурирующих гипотез с дешёвым различающим тестом»; при массовой гибели «основание для четырёх гипотез».
- Стало: «К каждой гипотезе до теста записывается исход, который её опровергает. Пока ни один тест не поставлен, диагноз шагов не определяет, кроме самих тестов, самого дешёвого первым. Диагноз, записанный до перестройки, после её провала меняется только по результату нового теста».
- Отказ: любой провал объясняется задним числом, поиск не меняется \[И\].
- Проверка \[Г\]: аудит журнала. Диагноз без записанного опровергающего исхода недействителен. Смена диагноза без нового теста — флаг.

**П6 (Р1-7, Р2-3). §5, «Выбор шага».**

- Было: «отношением различающей силы к цене».
- Стало: «Различающая сила — число пар конкурирующих гипотез, которые шаг по предсказаниям, записанным до шага, разводит на разные исходы. Цена — в единицах бюджета ядра. Обе величины пишутся до шага».
- Отказ: выбор шага произволен при видимости оптимизации \[И\].
- Проверка \[Г\]: два координатора независимо ранжируют три шага по записям. Расхождение рангов — сигнал, порог задаёт Э2.

**П7 (Р1-8). §9, сжатие карты.**

- Было: «Карта не длиннее 8 000 знаков».
- Стало: «Карта не длиннее предела, записанного в ядре на Э2».
- Отказ: прямое противоречие вводному «числовые пороги здесь не задаются» \[Ф: оба текста в документе\].
- Проверка: поиск числовых порогов в тексте методологии даёт ноль.

**П8 (Р1-9). §6, «Проверка проверки».**

- Было: «на пустых и испорченных данных: не упала — брак».
- Стало: «На пустых и испорченных данных процедура обязана вернуть явный отказ "вход некорректен" и не выдать подтверждение. Подтвердила вход или упала без записанной причины — брак».
- Отказ: отказоустойчивый проверяющий объявлен негодным, а падающий без причины допущен \[И: буквальное чтение\].
- Проверка \[Г\]: проверяющий, возвращающий INVALID\_INPUT, проходит. Подтверждающий пустой вход бракуется.

**П9 (Р1-10). §6, «Независимость».**

- Было: «Независимы: исполняемый код; формальная проверка; …».
- Стало: добавить «Проверки независимы, только если не разделяют спецификацию, аксиомы, данные и источник. Общий источник — одно свидетельство, сколько бы инструментов его ни повторяло».
- Отказ: зависимые проверки засчитаны как независимые, ошибка уходит в постоянную память \[И\].
- Проверка \[Г\]: внести одну неверную аксиому в спецификацию двух проверяющих. Реестр засчитывает один голос, требование «две/три независимых» не выполнено.

**П10 (Р1-11). §6, таблица «Сколько проверок нужно».**

- Было: класс ставок не определён.
- Стало: «Класс присваивает секретарь журнала по списку того, на что решение влияет: план, метод, перестройка, постоянная память. Автор заявки класс не выбирает. Понизить класс может только судья, записью».
- Отказ: строгость проверки зависит от выбранной заявителем категории \[И\].
- Проверка \[Г\]: две независимые классификации одной заявки совпадают. Понижение без записи — флаг.

**П11 (Р1-12). §2, Г2.**

- Было: «каждая неудача сужает поиск».
- Стало: «ямы-предикаты сужают пространство, свидетельства усиливают или ослабляют диагноз (§7)». Опровержение прежнее: число повторов тупиков не падает.
- Отказ: гипотеза противоречит §7, а её опровержение неизмеримо \[Ф: §2 и §7\].
- Проверка \[Г\]: 50 неудач без доказанных границ не дают засчитанного сокращения пространства.

**П12 (Р1-13). §1, опровержение третьего пункта.**

- Было: «при равном бюджете».
- Стало: «при равном полном бюджете: проверки, диагностика, управление, окна решений владельца».
- Отказ: дорогая система объявляет преимущество при худшей эффективности \[И\].
- Проверка \[Г\]: на одном полигоне сравнить результат при учёте и без учёта накладных. Вывод должен меняться там, где накладные велики.

**П13 (Р1-14). §11, класс E.**

- Было: «задачах, не участвовавших в настройке».
- Стало: «Набор отложенных задач фиксируется отпечатком в журнале до первого прогона настройки. Менять его после просмотра результатов переноса нельзя».
- Отказ: отбор удачных задач имитирует рост способности \[И\].
- Проверка \[Г\]: набор, собранный после просмотра результатов, не проходит сверку отпечатка по времени.

**П14 (Р2-2). §1 и §2.**

- Было: два разных сравнения без правила на расхождение.
- Стало: «Г3 подтверждена, только если перестройка с диагнозом выигрывает и у плацебо, и у фиксированной конфигурации при равном полном бюджете. Расхождение — "не подтверждено"».
- Отказ: центральная гипотеза выживает без решающей проверки \[И\].
- Проверка \[Г\]: синтетический случай «плацебо лучше, фиксированная не хуже» даёт вердикт «не подтверждено».

**П15 (Р2-4). §4, «после k перестроек».**

- Было: k без способа выбора, хотя вводная обещает способ.
- Стало: «k выводится на Э2 из цены ошибки диагноза и фиксируется до первого цикла. Смена k записывается до цикла с причиной и не продлевает идущую серию».
- Отказ: запрет перестройки откладывается подбором k задним числом \[И\].
- Проверка: сверка k в журнале с записью Э2. Расхождение — флаг.

**П16 (Р2-8). §11, класс E.**

- Было: задано только «ноль — не подтверждено».
- Стало: «Заявка класса E требует результата на заранее зафиксированных отложенных задачах при сравнении с контролем и числа повторений, назначаемого Э2. Единичный сохранившийся приём — наблюдение, не заявка».
- Отказ: самообучение объявлено по единичному случаю \[И\].
- Проверка \[Г\]: один сохранённый приём на одной задаче не даёт права на заявку.

**П17 (Р2-9). §7, яма-предикат.**

- Было: «доказанные границы» без вердикта.
- Стало: «Границы признаются доказанными вердиктом §6 уровня расчёт, контрпример или формальное доказательство. Согласие моделей не годится. Вердикт заверяет судья, не автор неудачи».
- Отказ: свидетельство произвольно превращается в запрет и закрывает направление \[И\].
- Проверка: сжатие карты (§9, п. 5) отвергает яму без ссылки на такой вердикт.

**П18 (Р2-10). §2, «Г1 и Г2 — необходимые условия».**

- Было: без метки и опровергающего опыта.
- Стало: «\[Г\] Необходимость Г1 и Г2 опровергается так: если выигрыш Г3 сохраняется при отключённом накоплении ям и при проверке без дисциплины Г1, они не необходимы».
- Отказ: непомеченная посылка защищает Г3 от опровержения \[Ф: нарушение правила меток вводной\].
- Проверка: опыт с отключением — результат пишется в журнал.

## Отклонено

- **Р1-3:** определения В1–В3 лежат в словаре по построению; их проверка относится к словарю, а не к этому тексту.
- **Р2-5:** порог ставит владелец до калибровки именно для того, чтобы его нельзя было подогнать; воспроизводимость расчёта владельца — вкус.
- **Р2-6:** резерв ограничен критерием «кандидат в выразимость в срок» (§5, §8), удобное направление сгорает по сроку.
- **Р2-11:** сведение Б1 к перебору методология сама объявила опровергающим исходом (§1) и «бессилием» (§4), нарушения нет.

## Не закрыто

- **Остаток Р1-6:** два диагноста могут дать несовместимые диагнозы по одним данным. П5 лишь заставляет записывать опровергающие исходы. Чтобы закрыть, нужна эмпирическая мера согласия диагностов на пилоте (Э2) и порог, ниже которого диагноз не принимается.
- **Остаток Р1-10:** общая ложная предпосылка всех проверяющих не ловится ничем внутри системы (§6, «неустранимые дыры»). Нужен внешний канал из М7 с проверкой способом, не зависящим от моделей.
- **Остаток Р1-2:** число повторных запусков (П2) неизвестно до пилота. Нужны данные о разбросе на полигоне.
