## Цикл

Команды запускать из папки `tools/` серии: `python3 -I avatar.py <команда>`.

1. Если `notes/heartbeat` свежее 35 минут, серию ведёт другая сессия: закончить работу, ничего не делая.
2. `status`. Если в `state.json` есть `current` и кнопка запуска не «Остановить», выполнить `finish`.
3. Если `current` нет — `start`. Ответ `ALL_DONE` означает конец серии (раздел «Конец»). Если схема не установлена (`select` вернул `absent`) — сначала `install`.
4. `watch` в фоне, без опроса вручную. По событию:
   - `owner`: прочитать отзыв в указанном файле, решить, какие замечания учесть, а какие отклонить. Записать решение в файл (2–5 предложений, по существу) и выполнить `owner <файл>`. Снова `watch`.
   - `modal`: окно неполного раунда — нажать «Пропустить участника» для необязательной модели (GPT и Claude обязательные, остальные нет). Информационное окно — закрыть. Снова `watch`.
   - `timeout`: посмотреть карточки. Необязательная модель молчит больше 15 минут — пропустить. Снова `watch`.
   - `ended`: `finish`, затем шаг 3.
5. Лимит Claude: остановить прогон, выполнить `finish`, затем `synth gpt` и `start` (автор свода — GPT, проверяющий — DeepSeek). Когда лимит Claude снимется, вернуть `synth claude`. Лимит GPT: остановить прогон, записать вопрос в `blocked` с причиной и выйти, следующий запуск продолжит.
