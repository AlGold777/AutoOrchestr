Практичный ответ для команды, которая строит мобильное приложение для 3D-аватаров: волосы, бороду и брови нельзя решать одной технологией. Надёжнее всего разделить конвейер на два этапа: реконструкция (получение представления из съёмки) и рендеринг в реальном времени (показ на телефоне). Для каждого этапа есть несколько жизнеспособных вариантов с разными компромиссами.Варианты представления и рендеринга1. Пряди (strand-based) с LOD-упрощением. Это самый физически честный путь: волосы и борода моделируются как отдельные кривые. Для мобильного рендеринга критичен уровень детализации (LOD): вблизи показываются пряди, вдали — упрощённые карты или меньшее число прядей. Unity развивает программный растеризатор для strand-based волос, чтобы повысить производительность и сглаживание при большом количестве прядей. В Unreal Engine strand-рендеринг официально не поддерживается на мобильных платформах, а skinned-привязка грома к мобильному скелету недоступна из-за стоимости. Это проверено по документации Epic. Практический вывод: «чистые пряди» на телефоне возможны только с очень агрессивным LOD и, скорее всего, не для всех типов причёски.-33-412. Карты (card-based) и гибридные меши. Карты — это текстурированные полупрозрачные плоскости, которые имитируют объём волос. Они поддерживаются на всех платформах, включая мобильные, и остаются основным способом показа сложных причёсок в real-time на слабом железе. Для бровей и короткой бороды карты или тонкие меш-слои часто дают лучший баланс качества и стоимости, чем полноценные пряди.-413. Gaussian Splatting (3DGS) для «пушистых» зон. Гауссовы сплаты хорошо подходят для волос и бороды, потому что не требуют явной геометрии поверхности и естественно передают полупрозрачность. Гибридная схема «меш для кожи + 3D-гауссианы для волос и бороды» уже предложена в Gaussian Pixel Codec Avatars (GPiCA, декабрь 2025): треугольный меш эффективно представляет поверхность лица, а гауссианы — несурфейсные области, включая волосы и бороду, с единым дифференцируемым пайплайном и рендерингом на мобильных устройствах. Это проверено по аннотации статьи. Ограничение 3DGS — необходимость сортировки примитивов по глубине, что тяжело для мобильных GPGPU; однако существуют обходы, например многослойные оболочки с фиксированным порядком рендеринга и числом сэмплов на луч всего 3–9, что специально сделано для мобильных устройств.-15-16-4. Многослойные «оболочки» (Volumetric Surfaces). Этот подход учит несколько полупрозрачных SDF-мешей с адаптивным шагом и рендерит их растеризацией в фиксированном порядке. Он даёт real-time синтез пушистых геометрий, таких как волосы и мех, на маломощных ноутбуках и смартфонах, превосходя MobileNeRF в моделировании объёмных волос. Это также проверено по CVPR 2025 paper note. Минус — это скорее представление для рендеринга, чем готовый инструмент реконструкции из бытовой съёмки.-51Реконструкция из съёмкиДля мобильного сценария важно не только качество, но и время/удобство для пользователя.Скан с нескольких ракурсов. SIGGRAPH 2025 представил полностью автоматизированный мобильный скан, который восстанавливает strand-based причёску из снимков на телефоне. Реконструкция занимает две минуты и выдаёт чистый ассет, пригодный для 3D-редакторов и игровых движков. Этот же подход описан как mobile-first pipeline: несколько поворотов головы, облачная обработка, CNN предсказывает положение и плотность прядей, а дифференцируемый рендеринг уточняет геометрию. Это проверено по материалам SIGGRAPH и Copresence. Ограничение: облачная обработка и «несколько изображений» — не строго один кадр.-21Реконструкция из одного изображения / короткого видео. Методы вроде Vid2Haircut восстанавливают strand-based причёску из монокулярного видео с движением головы; одно-ракурсные подходы страдают от неоднозначностей в окклюзированных зонах, например на затылке. Для продукта это означает: если требование — «одно селфи», придётся либо использовать сильные приоры (и мириться с неточностями), либо просить пользователя сделать короткий видео-облёт.-22Борода и брови. Для лицевой растительности существует pipeline, который автоматически восстанавливает бороду, усы, ресницы и брови из multi-view изображений, конвертируя неструктурированное 3D-гауссово представление в явные кривые (strand-based). Это проверено по аннотации. Для бровей отдельно отмечается, что их нельзя обрабатывать так же, как длинные волосы: в одном из подходов брови выделяются в отдельные кластеры с иным масштабом и ориентацией.-24-71РекомендацияДля команды, которая строит MVP с реалистичным, но работающим на телефоне аватаром, я бы рекомендовал гибридную слоёную архитектуру:Кожа и лицо — меш (высокая эффективность для поверхностей).Волосы — strand-based Gaussian splatting или многослойные оболочки для дальней/средней зоны, с LOD-переключением на карты вблизи краёв экрана или на слабых устройствах. Это компромисс между реалистичностью пушистой геометрии и мобильной производительностью.Борода и брови — либо отдельные strand-based кластеры (если бюджет позволяет), либо карты/тонкие меш-слои, потому что для короткой растительности выигрыш от полноценных прядей меньше, чем стоимость.Реконструкцию на первом этапе лучше делать облачной и асинхронной: пользователь снимает короткое видео/несколько ракурсов, сервер восстанавливает модель за минуты, телефон получает уже сжатую, оптимизированную под рендеринг версию.
