## Краткий вердикт

Для мобильного продукта «снял телефоном → получил похожий, анимированный, real-time аватар» оптимален **гибрид**: параметрический каркас класса SMPL-X как скелет и геометрическая «начинка» в виде Gaussian Splatting, привязанная к мешу. Чистые подходы проигрывают гибриду по ключевым продуктовым метрикам. Ниже разбор.

## Варианты решения

## 1. Параметрическая модель (SMPL-X)

SMPL-X — унифицированная параметрическая модель тела, лица и рук: 10 475 вершин, 54 сустава (включая челюсть, глазные яблоки, пальцы), управляется параметрами позы θ, формы β и мимики ψ, деформация через linear blend skinning с корректирующими блендшейпами [проверено: официальный репозиторий SMPL-X].[github](https://github.com/vchoutas/smplx)

Плюсы:

- Анимация «из коробки»: ретаргетинг позы, мимики (совместимая семантика с ARKit blendshapes), рук — стандартная инженерная задача [экспертная оценка, не проверено по источнику].
- Легкий рендер: десятки тысяч треугольников — тривиально для мобильного GPU [не проверено по источнику].

Минусы:

- **Сходство**. Модель воспроизводит пропорции тела, но не одежду, прическу и фототекстуры; выглядит как «колбасный человечек». Даже accuracy-ориентированные методы подгона дают MPJPE ~50 мм [проверено].[link.springer](https://link.springer.com/article/10.1007/s00138-025-01745-1)
- Лицо в SMPL-X уступает специализированным моделям класса FLAME; есть адаптации вроде SMPLX-Lite для фотореалистичного движимого рендера, но они сами опираются на студийный скан (32 RGB + 48 IR камер) [проверено].[arxiv](https://arxiv.org/html/2405.19609v1)
- **Лицензия**: SMPL-X распространяется по бесплатной, но ограничивающей исследовательской лицензии — коммерческое использование требует отдельного согласования с Max Planck [общеизвестный факт из документации модели; в найденных источниках не верифицировано — требуется проверка юристом].

## 2. Нейронная реконструкция сетки (implicit → mesh)

Классические и современные подходы (функция-поверхность, марширующие кубы, feed-forward регрессия меша). Свежий ориентир — IDOL: feed-forward одношаговая фотореалистичная 3D-реконструкция человека из одного изображения, опенсорс, обучена на синтетическом датасете HuGe100K с выровненным SMPL-X [проверено].[github](https://github.com/yiyuzhuang/IDOL)

Плюсы: на выходе — стандартный mesh с топологией, удобен для Unity/Unreal, colission, rigging [не проверено по источнику].

Минусы:

- Детали (волосы, складки одежды) теряются при ремешинге; текстурные артефакты на закрытых зонах [не проверено по источнику].
- Feed-forward методы из 1–2 фото «дорисовывают» невидимое (спина, затылок) — ошибка прямо бьет по узнаваемости [экспертная оценка].
- Анимированность: сетку еще надо привязать к скелету и задать коррективы — для этого все равно тянется SMPL-X-подобный каркас (IDOL явно использует выровненный SMPL-X) [проверено].[github](https://github.com/yiyuzhuang/IDOL)

## 3. Gaussian Splatting (чистый 3DGS)

рендер-представление из полупрозрачных 3D-гауссиан с растеризацией сплаттингом; в аватарах гауссианы инициализируют в каноническом пространстве и деформируют поза-зависимым модулем [проверено].arxiv+1

Плюсы — скорость: 300+ FPS на десктопном GPU и стабильные 30 FPS на iPhone 13 (SplattingAvatar) [проверено]; 3DGS-Avatar дает ~50 FPS инференса против 0,1–0,2 FPS у нейрорадиационных бейзлайнов (HumanNeRF, ARAH) — ускорение в 250–500 раз [проверено].arxiv+1

Минусы чистого 3DGS:

- Анимация неявная: деформация гауссиан требует привязки к телу — на практике это и есть гибрид (SMPL mesh + гауссианы) [проверено по методам].arxiv+1
- Размер данных и сортировка гауссиан — узкое место на мобиле; требуются квантизация (FP16 MLP, UInt16 сортировка) и асинхронный инференс [проверено: меры из TaoAvatar].[arxiv](https://arxiv.org/html/2503.17032v1/)
- Детерминированность рендера в движке (Unity/Unreal/ARKit) требует кастомного растеризатора [не проверено по источнику].

## 4. Гибрид (меш-каркас + 3DGS) — состояние науки

Ориентиры, все проверены:

- **SplattingAvatar**: гауссианы, встроенные в треугольную сетку SMPL-X/FLAME по монокулярной видеопоследовательности; >300 FPS десктоп, 30 FPS iPhone 13.[arxiv](https://arxiv.org/html/2403.05087)
- **TaoAvatar**: полноростовые говорящие аватары; шаблон ~22k вершин / 45k граней (включая одежду, волосы, обувь поверх SMPL-X), гауссианы привязаны к треугольникам как «текстуры» и движутся с мешем; 2K-рендер 90 FPS на Apple Vision Pro; анимация считается 20 FPS, рендер интерполирует до 90. Судя по заметке-обзору, PrismAvatar дает 60 FPS на iPhone 14 Pro и iPad Pro [ — источник неавторитетный, цифру перепроверить по arXiv:2502.07030].[arxiv](https://arxiv.org/html/2503.17032v1/)
- **Instant Skinned Gaussian Avatar**: генерация фотореалистичного аватара за ~5 минут, целиком на смартфоне; скан ~1 мин на iPhone 13 Pro, остальной препроцессинг ~30 c; деплой через WebXR в VR/AR/web.[arxiv](https://arxiv.org/html/2510.13978)
- Скиннинг гауссиан: >200 FPS для шести одновременных аватаров на ноутбучной 3080 Ti (неавторитетный источник, трактовать осторожно).[research.moverse](https://research.moverse.ai/articles/skinned-gaussian-avatars/skinned-gaussian-avatars.html)

## Рекомендация для команды

1. Каркас: SMPL-X (или его SMPL-подмножество + FLAME-голова, если лицензия упрется в ограничения). Фитинг позы/формы по мультивью-видео оборота телефоном; ожидаемая геометрическая точность порядка сантиметров — это нормально, продукт продает «похожесть», а не миллиметры [проверено по п.1].
2. Аппеаранс: 3DGS, привязанный к треугольникам меша (архитектура SplattingAvatar/TaoAvatar) — дает фотореализм, поза-зависимую одежду и real-time на мобиле [проверено].arxiv+1
3. Канва обучения: 10–20 секунд съемки; аватаров-обучение на девайсе (≤5 мин на смартфоне уже доказано ) или быстрый серверный фит, если нужен контроль качества [архитектурное решение, не из источников].[arxiv](https://arxiv.org/html/2510.13978)
4. Анимация: поза — ретаргет на скелет, мимика — ARKit-совместимые параметры ψ; рендер — свой сплаттинг-растеризатор + интерполяция кадров (анимация 20 FPS → рендер 60–90 FPS) [проверено по TaoAvatar].[arxiv](https://arxiv.org/html/2503.17032v1/)

## Числа и ограничения (все по источникам)

- Рендер 3DGS-аватара на iPhone 13: 30 FPS; на iPhone 14 Pro: ~60 FPS (требует перепроверки); Vision Pro: 2K@90 FPS.arxiv+2
- Время создания аватара: ~5 мин на смартфоне.[arxiv](https://arxiv.org/html/2510.13978)
- Геометрия шаблона с одеждой: ~22k вершин / 45k граней; SMPL-X: 10 475 вершин.arxiv+1
- Точность фитинга SMPL-X по данным с глубиной: MPJPE ~50 мм.[link.springer](https://link.springer.com/article/10.1007/s00138-025-01745-1)
- Ограничения: чистое освещение и оборот вокруг человека не гарантируют качество невидимых зон; головные уборы/очки/длинные волосы — деградация [экспертная оценка]; мобильные тепловые лимиты при >сотнях миллионов гауссиан потребуют компрессии [не проверено по источнику; в свете квантизация необходима].[arxiv](https://arxiv.org/html/2503.17032v1/)

## Риски

- **Лицензионный**: условия SMPL-X для коммерческого продукта — проверить до старта [не верифицировано источниками выше].
- **Полнота захвата**: зоны, не попавшие в кадр, дорисовываются генеративно — риск «чужой спины»; митигация — UI-мастер съемки (как у сканеров типа Scaniverse-пайплайна) [частично проверено].[arxiv](https://arxiv.org/html/2510.13978)
- **Зрелость стека**: full-body 3DGS-аватары менее зрелые, чем «только-голова» методы [проверено по обзору, слабый источник]; публичных SDK продакшн-качества под iOS/Android нет — растеризатор писать самим [не проверено по источнику].[github](https://github.com/Ludentes/Face-Research/blob/main/07-3dgs-avatars.md)
- **Устройства**: заявленные FPS — на iPhone 13/14 Pro; бюджетный Android — незамерянная зона [не проверено по источнику].

Итог: гибрид «SMPL-X-скелет + mesh-embedded Gaussian Splatting» — единственный вариант, одновременно покрывающий похожесть, анимированность и real-time на телефоне; это подтверждено как минимум тремя независимыми работами 2024–2025 годов.arxiv+2
