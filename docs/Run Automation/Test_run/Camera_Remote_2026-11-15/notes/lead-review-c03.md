Проход c03: три модели «согласен с правками», Qwen «не согласен». Возражение Qwen опирается на факты, которых он не знал. Вот что я проверил по первоисточникам.

Подтверждено:
- tcholewa/ClickNovaShutter существует (ESP32 T-Display, создан 18.07.2026). BLE HID Consumer Control: Volume Increment 0xE9 и отпускание, iPhone 16 Pro, «ровно один снимок на нажатие». Камера должна быть открыта заранее, Android вне объёма, версия iOS в README не названа, байты дескриптора в README нет (они в исходниках).
- Aleksander-Drewnicki/BLE_HID_EXAMPLE имеет релизы с готовым APK: v2.7.0 (30.10.2026), v2.6.0, v2.5.0, v2.0.0. У форка rkissell релизов нет.
- jameellzx/iphone-cam-remote (ПК шлёт BLE HID Volume Up), релиз ESP32 «Working Camera Shutter on BLE HID» существуют.

Не подтверждено мной: проект Clak (поиск GitHub пуст), цитата Apple Accessory Design Guidelines R18 о запрете публиковать BLE HID стороннему iOS-приложению, разночтение по ww24/remote-shutter (по описанию репозитория это смартфонный BLE HID пульт; в итоге написано «M5Stack»).

Возражения Qwen снимаются так: ClickNova и APK существуют (см. выше); «AirDrop и Quick Share несовместимы» опровергается Google для части Android-моделей. Остаётся его верное замечание: связка Android → iOS 26 нигде не проверена.
