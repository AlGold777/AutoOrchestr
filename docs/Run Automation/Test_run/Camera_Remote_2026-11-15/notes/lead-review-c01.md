Подтверждено мной по источникам:
- Пульты для селфи шлют HID Consumer Control «Volume Up» (0xE9), штатная Камера iPhone по нему снимает (Nordic DevZone, «Trigger iOS Shutter via BLE»). Apple: кнопка громкости в Камере делает снимок (iPhone User Guide).
- BluetoothHidDevice: API 28. В AOSP registerApp() отказывает, если приложение не на переднем плане, и регистрация снимается при уходе в фон (коммит «HID Device: Unregister inactive app»); в официальной документации этого нет.
- Camera Control на iPhone 16 по HID не запускается (форум разработчиков Apple). Пульт может менять только громкость звонка, если включено «Изменение кнопками» (Apple Community).

Пропущено или неверно в итоге:
1. BLE HID over GATT (HOGP) с Android через BluetoothGattServer не рассмотрен. Доказанный для iOS класс — именно BLE-пульты; итог смешал их с классическим HID и разобрал только его. Не найдено источника, что Android блокирует службу 0x1812.
2. Не названы готовые реализации для теста без разработки. Одна из найденных: rkissell/BLE_HID_EXAMPLE (BLE HID, режим только consumer control); нужно проверить исходник.
3. Регрессию дескриптора iOS 15→16 (Nordic) итог упомянул, но не выяснил, какой дескриптор работает на iOS 17–26.
