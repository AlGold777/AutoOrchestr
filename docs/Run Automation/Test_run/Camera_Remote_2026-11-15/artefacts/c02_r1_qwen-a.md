Его можно принять как эксперимент, а не гарантированный результат.По замечаниям ведущего:BLE HOGP не рассмотрен — подтверждаю. В итоге он упомянут, но разбор дан только для Android BluetoothHidDevice. Документация Android описывает BluetoothGattServer; HID over GATT использует службу 0x1812 по Bluetooth Assigned Numbers. Однако у Apple нет публичного документа, что произвольный Android-GATT-сервер гарантированно спускает Camera в iOS 17–26.Готовые реализации — не знаю. Не могу подтвердить работоспособность rkissell/BLE_HID_EXAMPLE на актуальных iOS/Android без проверки исходника и запуска.Регрессия дескриптора — подтверждаю. Решение упоминает iOS 15→16, но не даёт точных байтов для iOS 17–26 и не указывает, какой формат подтверждён.Дополнительно по пунктам, которые ведущий пометил как подтверждённые:Идея пультов с Volume Up правдоподобна, но подтверждена только как класс пользовательских аксессуаров, не как контракт для приложения на Android в iOS 26.Требование переднего плана для BluetoothHidDevice в официальной документации Android прямо не описано; ссылку на коммит AOSP без официальной страницы нельзя считать документацией платформы — не знаю.Утверждение про Camera Control на iPhone 16 и HID не могу подтвердить без конкретного источника в документации разработчика; ограничение логично, но не является доказательством для этого решения.Возражения и проверки:Неверно называть HID-спуск «рекомендуемым» без подтверждения. Публично подтверждено только то, что физическая кнопка громкости снимает кадр (iPhone User Guide) и что HID Consumer Page 0x0C имеет Volume Increment 0xE9 (HID Usage Tables). Связка «обычное Android-приложение → iOS 26 Camera» в документации отсутствует. Исправление: считать путь исследовательским. Дешёвая проверка: один тест с включённым журналом на обоих телефонах.Смешаны транспорты. Android BluetoothHidDevice — профиль классического Bluetooth HID, а не автоматический BLE HOGP. Это разные стеки и дескрипторы. Исправление: явно выбрать два отдельных теста: BR/EDR через BluetoothHidDevice и BLE через BluetoothGattServer.Отсутствует рабочий report descriptor. Без корректной коллекции, usage page, report ID и нулевого отчёта для release событие может не дойти. Исправление: не фиксировать архитектуру до получения минимального подтверждённого дескриптора. Проверка: поднять минимальный GATT-сервер с одной кнопкой и убедиться, что громкость на iPhone меняется; затем проверить Camera.Возврат файла переоценён. Штатная Camera пишет в Photos; помощник может читать только при разрешении пользователя и ограничениях PhotoKit. iCloud Photos, AirDrop и общие альбомы не дают программного «забрать файл сразу» без действий пользователя. Исправление: после спуска помощник наблюдает PHPhotoLibrary changes и экспортирует оригинал по локальной сети, когда приложение может работать. Проверка: снять кадр вручную и проверить, что помощник видит новый asset.iPhone как управляющий не подтверждён. Проверка: поиск в документации Core Bluetooth по HOGP/HID Device.Пропущен запуск самой Camera.
