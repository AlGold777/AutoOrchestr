2. Нумерованные технические возражения

HOGP ≠ гарантия спуска. Android BluetoothGattServer (API 18), Classic BluetoothHidDevice (API 28) и Bluetooth SIG HOGP 1.2 документированы; обработка Volume Up штатной Camera не гарантирована. Проверка — реальный снимок. 
Android Developers
+2

iPhone-контроллер нельзя утверждать как поддерживаемую архитектуру. Ограничения CoreBluetooth сохраняются. Проверка — сопоставление реализации с §41.13 Apple.

Wi-Fi/интернет не заменяют системный HID. Публичного API удалённого затвора Camera нет; sandbox не даёт помощнику управлять чужим процессом. Минимальное ослабление — собственная AVFoundation-камера либо внешний аппаратный пульт.

3. Финальный протокол первой проверки

Android 12+: установить APK v2.7.0; зафиксировать SHA-256, модель Android, модель iPhone, версию и сборку iOS.

Consumer Control → BLE advertising → сопряжение iPhone.

При закрытой Camera проверить изменение громкости от Volume Up.

Открыть штатную Camera, режим «Фото». Передать десять отдельных нажатий с отпусканием.

Записать экраны, события HID, количество новых фотографий.

Успех: 10 команд → 10 снимков. Отказ: определить этап — pairing, subscription, HID или Camera.

Повторить после переподключения. При изменении дескриптора удалить сопряжение.

Отдельно проверить извлечение оригинала через PHAssetResourceManager.
