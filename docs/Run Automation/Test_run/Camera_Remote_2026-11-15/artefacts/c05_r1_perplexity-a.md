Возражения к решению

Версии iOS устарели в самом решении. Ведущий фиксирует iOS 27.2.1 и 26.7.3 от 09.11.2026. Исправление: привязка к номеру сборки, не к ветке. Дешёвая проверка: Settings → General → About + Apple Security Releases перед серией.

«iOS 26.5.2 из журнала ClickNova» — неподтверждённая ссылка. Исправление: цитировать файл и строку либо пометить «не проверено». Проверка: открыть docs/ в репозитории.

Требование Battery+DIS как М (HOGP v1.2, таблица 3.1). Спецификация — вероятно верно, версию/дату не подтверждаю (как ведущий). Важно: обязательность по спецификации ≠ обязательность для работы — дешёвые пульты без полного набора сервисов с iPhone работают. Проверка: nRF Connect — осмотреть GATT рабочего селфи-пульта.

Пропущена неэквивалентность физической и HID-кнопки в конкретных состояниях: при заблокированном экране, подсвеченном HUD громкости или вызове поведение может отличаться. Исправлено пунктом рисков ведущего.

Classic HID (BluetoothHidDevice) как резерв — малореалистичен: iOS не поддерживает Classic HID-профиль для consumer-remote; оставлять, но с минимальным приоритетом. Проверка: один прогон при отказе BLE.

Решение цельное: HID-путь — единственный платформенно разрешённый; публичного Camera shutter API нет, это верно; возврат файла через PHAssetResourceManager корректен.
