Оценка замечаний ведущего1. Подтверждаю частично. Apple User Guide для iOS 26 документирует спуск физической кнопкой громкости. Nordic подтверждает BLE HID Consumer Control 0xE9 для штатной Camera на iOS 15 и восстановление работы на iOS 16.1. На iOS 17–26 конкретный дескриптор не верифицирован. 2. Подтверждаю, с уточнением. BluetoothHidDevice существует с Android API 28. Более того, актуальная официальная документация Android прямо указывает автоматическую отмену регистрации вне foreground. Утверждение, что это описано исключительно в AOSP, устарело. 3. Не знаю по документации. Отсутствие HID-доступа к отдельной кнопке Camera Control и возможное изменение громкости описаны пользователями, но не установлены нормативной спецификацией Apple для всех iOS 26.Нумерованные возражения и исправления4. Неверный приоритет транспорта. Classic HID через BluetoothHidDevice — документированный Android API, но не проверенная связка с Camera iOS 26. BLE HOGP ближе к демонстрации Nordic: BluetoothGattServer.addService() публичен с API 18; запрета Android на UUID 0x1812 документация не устанавливает. Исправление: сначала BLE HOGP, Classic параллельно как резерв. Проверка: сопряжение, подписка на Input Report, десять спусков и десять новых файлов Photos. 5. Пропущен Android-прототип. rkissell/BLE_HID_EXAMPLE действительно описывает BLE-периферию с базовым Consumer Control и Volume Up. Но README не доказывает совместимость с iOS 26; готового подтверждённого APK нет. Исходные файлы реализации отдельно не верифицированы. Проверка: собрать проект, включить Basic mode, проверить спуск и ошибки bonding. 6. Отсутствует подтверждённый дескриптор для iOS 17–26. Nordic публикует байты report map и press/release для эксперимента с iOS 16.1, однако не подтверждает их на iOS 26. Нельзя выдавать 0xE9 за полный пакет: необходимы Report ID, согласованный формат полей, release и bonding. Проверка: повторить пример Nordic; сохранить GATT trace и дескриптор успешного запуска. 7. Необоснованно исключён iPhone-контроллер. Apple документирует CBPeripheralManager как GATT-сервер, но не гарантирует HOGP-профиль устройства. Однако опубликованное в App Store приложение BT Remote: Keyboard & Trackpad реализует BLE HID на iPhone, включая команды громкости. Исходник открыт; реализация использует недокументированные особенности регистрации HID-сервиса. Это контрпример технической невозможности, хотя спуск Camera iOS 26 ещё нужно испытать. Проверка: сопрячь два iPhone, отправить Volume Up. 8. Возврат файла недооценён. PHPhotoLibrary документирован, но помощнику в фоне не гарантировано немедленное исполнение, пока Camera foreground. Надёжнее выгружать оригинал через iCloud Photos либо использовать PhotoKit и Wi-Fi после возврата помощника на экран. Shared Albums уменьшают разрешение; AirDrop совместим с Quick только на поддерживаемых Android. Проверка: сравнить SHA-256 оригиналов. Итог: HID-ввод сохраняет штатный конвейер Camera, но выполнение полного контракта на iOS 26 пока не доказано.
