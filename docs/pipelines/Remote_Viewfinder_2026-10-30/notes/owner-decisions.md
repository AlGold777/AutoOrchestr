# Решения владельца по Remote Viewfinder (2026-10-30)

Ответы на продуктовые вопросы из `review.md`, раздел D. Они обязательны для схемы v2 (шаг r4/r5 получает их как исходные данные) и для итоговой архитектуры.

| № | Вопрос | Решение | Следствия для архитектуры |
|---|---|---|---|
| 1 | Смена камеры при записи | **Запретить во время записи** | `SWITCH_CAMERA` отклоняется, пока `RecordFSM` в состоянии записи; сегментное переключение камеры убрать из потоков §6 и из §10; в UI B кнопка неактивна во время записи с пояснением. Снимается противоречие §6/§10. |
| 2 | Допустимая потеря при аварийном завершении A | **Не более ~1 секунды** | Нужна фрагментированная запись (fMP4/эквивалент на iOS и Android) с коротким фрагментом ≤ 1 с; проверка целостности и восстановление файла после смерти процесса; в план проверки — тест аварийного завершения. Сегменты по 10 мин остаются только как ротация файлов. |
| 3 | Подтверждение B на A | **Показывать модель устройства B** | На A в диалоге «Разрешить B?» — имя/модель устройства B (из TLS-рукопожатия или payload сопряжения). Одной модели недостаточно против подмены (два одинаковых телефона): в риски записать как остаточный, решение владельца принято. |
| 4 | Минимальные версии | **iOS 17+ и Android 10+** | Зафиксировать в §1/§7; API камеры, Local Network, foreground service — по этим версиям. |
| 5 | Файл записи | **Только хранилище приложения A** | Экспорт в «Фото»/галерею вне MVP; в разделе «Вне MVP» указать. |
| 6 | Сеть без роутера | **Вручную через настройки системы** | Приложение показывает подсказку, как включить точку доступа и подключить второй телефон; параметры сети в QR не передаются. |
| 7 | Приёмка задержки | **5 ГГц и 2,4 ГГц** | Тестовая матрица удваивается по диапазонам. Риск: P95 ≤ 200 мс на 2,4 ГГц может не достигаться — зафиксировать критерий и план проверки; если не достигается, владелец решает, ослаблять ли цель для 2,4 ГГц. |
| 8 | Задержка в интерфейсе B | **Только в диагностике** | Индикатор задержки в рабочем экране не нужен. |
| 9 | Ориентация записи | **По моменту старта записи** | Одна ориентация на файл; поворот телефона во время записи не меняет файл. |

Ранее принято (прогон 1): один зритель (1:1); запись на телефоне A; сопряжение QR; приоритет — минимальная задержка; звук не передаётся и не записывается; цель P95 ≤ 200 мс.
