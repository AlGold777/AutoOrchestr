# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Чекбокс «Вложенные файлы» расположен над таблицей. Кнопка `Save` сохраняет результат как Markdown-таблицу; соседняя кнопка копирует таблицу.

Выгрузка — таблица GitHub Flavored Markdown (GFM), совместимая с Markdown-просмотрщиками, которые отображают GFM-таблицы. В таблице есть колонки: `Запрос не вставился`, `Запрос не отправился`, `Модель не сгенерировала ответ`, `Ответ не вставился в карточку`, `Ответ обрезан`, `Вложения не вставились`, `Вставились не все вложения`. При включённом чекбоксе вложений перед таблицей выводится отдельная строка `Вложенные файлы: Да`. В строках моделей остаются только модели, где отмечена хотя бы одна проблема; в отмеченных ячейках записывается `Да`, остальные ячейки оставляются пустыми. Неотмеченное значение колонки «Модель не сгенерировала ответ» — `-`: оно полностью пропускается, как и отметка `Нет`. При отмеченной проблеме платформы записывается `проблема платформы`. Если проблем и вложений нет, выгрузка содержит только заголовок и разделитель таблицы.
