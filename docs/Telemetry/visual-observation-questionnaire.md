# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Интерфейс состоит из строки «Вложенные файлы» и таблицы с моделями и этапами; значок скачивания сохраняет результат как Markdown-таблицу.

В ячейках пяти этапов круглый чекбокс: отмечено — `Да`, не отмечено — `Нет`. Для колонки «Модель не сгенерировала ответ» неотмеченное значение — `-` и не считается проблемой; отмеченное значение — `проблема платформы`. Все чекбоксы изначально не отмечены. Флаг вложений выгружается отдельной строкой таблицы как `Вложенные файлы: Да/Нет`.
