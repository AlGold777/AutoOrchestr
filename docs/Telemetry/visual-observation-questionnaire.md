# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Чекбокс «Вложенные файлы» расположен над таблицей. Кнопка `Save` сохраняет результат как Markdown-таблицу; соседняя кнопка копирует таблицу.

Выгрузка — таблица GitHub Flavored Markdown (GFM), совместимая с Markdown-просмотрщиками, которые отображают GFM-таблицы. В таблицу включаются только колонки, где есть хотя бы одна отметка, и только модели с отмеченными проблемами. Для остальных моделей в включённых колонках ячейки остаются пустыми. Чекбоксы экспортируются как `Да`; значения из списков экспортируются без изменений. Значения `-` в списках не экспортируются. При отмеченной проблеме платформы в колонке «Модель не сгенерировала ответ» записывается `проблема платформы`; неотмеченное значение `-` и отметка `Нет` не попадают в результат. При включённом чекбоксе вложений перед таблицей выводится отдельная строка `Вложенные файлы: Да`. Если отметок нет, таблица не выгружается; если также не включены вложения, файл пустой.
