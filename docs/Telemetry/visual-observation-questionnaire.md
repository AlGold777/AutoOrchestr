# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Чекбокс «Вложенные файлы» расположен над таблицами. Первая таблица фиксирует проблемы по моделям; раздел `Pipeline` позволяет добавлять строки по шагам и моделям. Короткие заголовки Pipeline имеют пояснения при наведении. Кнопка `Save` сохраняет результат в Markdown; соседняя кнопка копирует его.

Выгрузка состоит из GFM-таблиц. В таблицы включаются только колонки, где есть хотя бы одна отметка, и только строки с отмеченными проблемами. Pipeline-строка идентифицируется номером/раундом, названием шага и моделью. Чекбоксы экспортируются как `Да`; значения из списков экспортируются без изменений. Значения `-` в списках не экспортируются. Для Pipeline в колонке «Управление» выбирается не сработавшая кнопка: `Пауза`, `Продолжить` или `Стоп`. При отмеченной проблеме платформы в колонке «Модель не сгенерировала ответ» записывается `проблема платформы`; неотмеченное значение `-` и отметка `Нет` не попадают в результат. При включённом чекбоксе вложений перед таблицами выводится отдельная строка `Вложенные файлы: Да`. Если отметок нет, таблицы не выгружаются; если также не включены вложения, файл пустой.
