# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Интерфейс состоит из строки «Вложенные файлы» и таблицы с моделями и этапами; значок скачивания сохраняет результат как Markdown-таблицу.

Выгрузка — таблица GitHub Flavored Markdown (GFM), совместимая с Markdown-просмотрщиками, которые отображают GFM-таблицы. При включённом чекбоксе вложений перед таблицей выводится отдельная строка `Вложенные файлы: Да`. В строках моделей остаются только модели, где отмечена хотя бы одна проблема; в отмеченных ячейках записывается `Да`, остальные ячейки оставляются пустыми. Неотмеченное значение колонки «Модель не сгенерировала ответ» — `-`: оно полностью пропускается, как и отметка `Нет`. При отмеченной проблеме платформы записывается `проблема платформы`. Если проблем и вложений нет, выгрузка содержит только заголовок и разделитель таблицы.
