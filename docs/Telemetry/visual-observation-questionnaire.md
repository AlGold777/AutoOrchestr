# Опросник визуального наблюдения

Для заполнения используйте [HTML-опросник](visual-observation-questionnaire.html). Чекбокс «Вложенные файлы» расположен над таблицей. Кнопка `Save` сохраняет результат как Markdown-таблицу; соседняя кнопка копирует таблицу.

Выгрузка — таблица GitHub Flavored Markdown (GFM), совместимая с Markdown-просмотрщиками, которые отображают GFM-таблицы. В таблицу включаются только колонки, где есть хотя бы одна отметка, и только модели с отмеченными проблемами. Для остальных моделей в включённых колонках ячейки остаются пустыми. В отмеченных ячейках записывается `Да`; при отмеченной проблеме платформы в колонке «Модель не сгенерировала ответ» записывается `проблема платформы`. Неотмеченное значение этой колонки — `-`, оно полностью пропускается, как и отметка `Нет`. При включённом чекбоксе вложений перед таблицей выводится отдельная строка `Вложенные файлы: Да`. Если отметок нет, таблица не выгружается; если также не включены вложения, файл пустой.
