# Опросник визуального наблюдения

Для заполнения проблем по отдельным моделям используйте [опросник моделей](visual-observation-questionnaire.html). Опросник Pipeline и спецификация его выгрузки находятся в отдельном [файле](pipeline-visual-observation-questionnaire.md).

Результаты опросника моделей экспортируются в GFM-таблицу: включаются только отмеченные колонки и строки с проблемами. Чекбоксы дают значение `Да`, значения списков экспортируются без изменений, дефисы и `Нет` пропускаются. Колонка «Модель не сгенерировала ответ» содержит только `проблема платформы` при установленной отметке. Вложенные файлы указываются отдельной строкой перед таблицей только при отмеченном чекбоксе.
