# Опросник визуальных проблем Pipeline

Заполняйте [отдельную HTML-форму Pipeline](pipeline-visual-observation-questionnaire.html). При открытии в таблице уже есть 10 строк — по одной на раунд 1–10. Каждая строка соответствует шагу и модели; `＋` добавляет дополнительную строку для ещё одного шага/модели. Короткие названия проблем имеют пояснения при наведении; в колонке «Управление» выберите не сработавшую кнопку: `Пауза`, `Продолжить` или `Стоп`.

Экспорт и копирование создают GFM-таблицу. В результат попадают только отмеченные колонки и строки с проблемами. Чекбоксы экспортируются как `Да`, выбранные действия — без изменений; значения `-` и пустые строки пропускаются. Отметка вложений экспортируется отдельной строкой над таблицей. Если нет проблем и вложений, файл пустой.
