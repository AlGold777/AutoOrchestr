# Опросник визуальных проблем Pipeline

Заполняйте [отдельную HTML-форму Pipeline](pipeline-visual-observation-questionnaire.html). Под заголовком отметьте модели, участвующие в прогоне. Таблица содержит 10 групп раундов; в раскрытых группах отображаются только выбранные модели. Нажмите `+` у раунда, чтобы показать модели, или `−`, чтобы скрыть их. Первая колонка закреплена при горизонтальной прокрутке. Короткие названия проблем имеют пояснения при наведении; в колонке «Управление» выберите не сработавшую кнопку: `Пауза`, `Продолжить` или `Стоп`.

Экспорт и копирование создают GFM-таблицу. В результат попадают только отмеченные колонки и строки с проблемами. Чекбоксы экспортируются как `Да`, выбранные действия — без изменений; значения `-` и пустые строки пропускаются. Отметка вложений экспортируется отдельной строкой над таблицей. Если нет проблем и вложений, файл пустой.
