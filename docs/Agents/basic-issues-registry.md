# Реестр открытых проблем Basic

Один список для движка Basic. Цель работы — не прогоны, а устранение препятствий, которые мешают прогону. Новую проблему, найденную в любом прогоне (включая прогоны других задач, например «Ловушка для комаров»), ведущий вносит сюда в тот же ход, со ссылкой на экспорт. Закрытая проблема получает версию и тест; «не проверено вживую» остаётся открытым хвостом, пока живой прогон не подтвердит.

Статусы: **ОТКРЫТО** — не сделано; **ЗАКРЫТО-Н** — исправлено и покрыто тестами, живой проверки нет; **ЗАКРЫТО** — подтверждено живым прогоном; **ПРОВЕРИТЬ** — по плану закрыто, независимого подтверждения кодом нет (аудит AUD-1).

Источники: R — ревью 2026-10-30 (`docs/pipelines/Remote_Viewfinder_2026-10-30/notes/review.md`, пункты A–E); L — живые прогоны на 2.81.945–948 и прогон по комарам.
