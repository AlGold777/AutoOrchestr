# Дополнение к спецификации страниц: входные файлы Basic


Общий модуль `results/input-files.js` добавляет `.basic-input-files-button` (📎) в Header окна модели справа от `.custom-card-length`, а также в Header настроек User. Скрытый `input[type=file][multiple]` принимает реальные файлы; `.basic-input-files-list` показывает имена, замену отсутствующего файла и удаление. Все операции отключены при активном прогоне. Это вход участника выбранного этапа, не файл-ответ. В окне выполнения User входные файлы доступны ссылками `.choice-dialog-input-file`. Метаданные сохраняются в `files`, байты — отдельно; подробности и ограничения: [входные файлы Basic](../Pipeline%20scenarios/basic-input-files.md).

Проверка без внешнего запроса: открыть карточку модели и User, проверить позицию 📎, выбрать локальный fixture через `DOM.setFileInputFiles`, сохранить/открыть заново, удалить, проверить отключение редактирования во время прогона. Не отправлять prompt реальным моделям без отдельного разрешения.
