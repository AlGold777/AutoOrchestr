# Самоадаптирующийся ИИ-исследователь

Система исследует научную проблему и одновременно собственный способ её решать: замечает, что мешает сам метод, меняет его и доказывает, что изменение помогло. Работает на AutoOrchestr Basic.

Статус: проект, к задаче не привязан, прогонов не было. Собран из четырёх исходных документов (V.2.1, V.3.2, схема запуска v1.1, задание v4.2); расхождения между ними сняты в [system/03-decisions.md](system/03-decisions.md).

## Главное в десяти строках

1. Ядро — задача, критерии, пороги, правила проверки, закрытые наборы, журнал — система не меняет. Меняет только владелец отдельной операцией с записью.
2. Всё остальное — конфигурация: представление задачи и приёмы ролей. Её и перестраивает круг обучения.
3. Предсказание записывается до проверки. Проверяющий — из другой группы моделей, в новом чате, без рассуждений автора.
4. Журнал — экспорты прогонов и цепочка их хешей; последняя строка регулярно уходит внешнему наблюдателю.
5. Прогресс считается в трёх валютах: исполнимое ограничение, новая выразимость, новая проверяемость.
6. Неудача записывается с причиной. Запретом становится только неудача с доказанными границами.
7. Перестройка — шесть полей с рискованным предсказанием и условием отката. Она испытывается против прежней конфигурации и против плацебо — изменения той же цены без диагноза.
8. Каждая перестройка, включая откаты, попадает в библиотеку: это память о том, как перестраиваться.
9. Система проверяется на полигоне — задачах с известным владельцу ответом — и на корпусе порч.
10. Заявление «система учится» делается только по опыту на задачах, не участвовавших в настройке.

## Чего пока нет

- Непрерывного режима в Basic: [process/04-endless-mode.md](process/04-endless-mode.md) описывает режим и то, что для него нужно. До этого цикл запускает владелец.
- Исполнения кода и собственного журнала в Basic: проверку исполняет модель или владелец, цепочку хешей ведёт владелец.
- Рецензии методологии моделями: это первый этап сборки.
- Корпуса порч, задач полигона и чисел порогов: они создаются по ходу сборки.
