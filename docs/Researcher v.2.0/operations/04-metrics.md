# Показатели

Показатель используется, только если у него названы источник, способ накрутки и защита. Числа берутся из записей цикла, карты и библиотеки; оценок «на глаз» нет.

## 1. Продвижение

| Показатель | Источник | Как накручивается | Защита |
| --- | --- | --- | --- |
| Прирост В1 | Число кандидатов, отсечённых новыми ямами-предикатами | Мелкие правила, отсекающие пустое | Считаются отсечённые кандидаты текущего пула |
| Прирост В2 | Пройденные тройные тесты | Переименование | Тест редукции определения; срок |
| Прирост В3 | Способы проверки с двумя числами | Проверка, которая всё пропускает | Калибровка; холостой прогон |
| Цена проверенного результата | Расход / результаты S1 и выше | Дробление результата | Счёт по заявкам |
| Превышение над наивным | Доля подтвердившихся предсказаний, отличных от наивных | Широкие предсказания | Требование отличия от наивного в заявке |
| Калибровка ставок | Ставка уверенности против исхода, по десяткам заявок | Ставки около 0,5 | Считается вместе с долей рискованных предсказаний |
| Решённые задачи полигона | Скрытый ответ | Узнаваемые задачи | Проверяющий мир; параметрическое порождение |

## 2. Целостность

| Показатель | Источник | Как накручивается | Защита |
| --- | --- | --- | --- |
| Доля ложных подтверждений | Полигон; аудит | Отказ от вердиктов: всё «неясно» | Считается вместе с долей «неясно»; три «неясно» подряд — стоп-правило |
| Доля пойманных посевов | Файл посевов владельца | Тревога на всё | Ложные тревоги считаются отдельно |
| Два числа проверяющих | Калибровка | Знакомая выборка | Выборка не повторяется |
| Общая слепая зона | Порчи, пропущенные всеми | — | Растёт — независимость считается только по способу |
| Отозвано аудитом | Список «К отзыву» | Аудитор согласен со всем | Подложенный ложный вывод в выборке |
| Расхождение зачётного и финального набора | Вскрытие финального | — | Один раз; у наблюдателя |
| Ложные блокировки ям | Пробные попытки по истёкшим ямам | Ямы не проверяются | Обязательная пробная попытка по сроку |
| Расхождения записей с ответами | Донесения контролёра | Контролёр молчит | Посев расхождений |

## 3. Перестройка

| Показатель | Источник | Как накручивается | Защита |
| --- | --- | --- | --- |
| Перестройка против плацебо, в единицах шума | Записи библиотеки | Слабое плацебо | Плацебо выбирается по номеру цикла, а не автором перестройки |
| Доля подтвердившихся предсказаний перестроек | Вердикты судьи | Осторожные предсказания | Засчитывается только рискованное |
| Доля откатов | Вердикты судьи | Отказ от перестроек классов C и D | Считается вместе с их числом; ноль за `tripwire_n` циклов — флаг |
| Доля сгоревших по сроку | Карта | Длинные сроки | Срок не длиннее карантина |
| Доля бюджета на перестройки | Расход | Косметические перестройки | Без рискованного предсказания не считается |
| Точность диагноста | Вживлённые дефекты | Диагноз «всё сразу» | Засчитывается одна названная причина |
| Перестроек до первого подтверждения, по задачам подряд | Библиотека | — | Не падает — «не учится перестраиваться» |
| Перенос | Задачи следующего проекта | Похожие задачи | Задачи выбирает внешний наблюдатель |

## 4. Устойчивость и человек

| Показатель | Источник | Как накручивается | Защита |
| --- | --- | --- | --- |
| Доля шагов без ответа | Записи `incomplete_step` | — | — |
| Циклов с одним проверяющим | Сводка, «в ослабленном виде» | — | Статус не поднимается |
| Минуты владельца на цикл и на принятую перестройку | Окно решений | Недосчёт | Записывается в окне сразу |
| Доля волевых решений | Решения владельца | Не помечаются | Контролёр сверяет решение со сводкой |
| Слабые предложения, принятые владельцем | Файл посевов | — | — |
| Расхождение с запечатанными ожиданиями | Сводка, строка 9 | Ожидания не записаны | Без `sealed-test.txt` ратификация не проходит |

## 5. Признаки самообмана

Докладчик называет их в сводке; два признака одновременно — флаг ручной проверки.

1. Ставки уверенности растут, калибровка нет.
2. Опровержений стало меньше при том же числе заявок.
3. Вердикты совпадают чаще, а проверок другим способом не прибавилось.
4. Расход растёт, валюты стоят.
5. Выигрыш есть на отладочном наборе и нет на зачётном.
6. Циклы стали короче, а посевы ловятся хуже.
7. Перестройки подтверждаются всегда.

## 6. Что показателем не является

Число гипотез, число шагов, число агентов, объём текста, согласие моделей, доля принятых квитанций. Организационные показатели говорят о здоровье системы, но не о продвижении к решению.
