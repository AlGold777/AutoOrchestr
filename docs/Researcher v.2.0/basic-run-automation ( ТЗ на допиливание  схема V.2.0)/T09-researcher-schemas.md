# T09 · Схемы Researcher используют новые поля

Ты — исполнитель. Твоя задача — включить в схемы системы `docs/Researcher v.2.0` поля, которые появились в Basic после заданий T04–T06: остановку по метке, пропуск не ответившего и повтор. Код расширения в этом задании не меняется, версия `manifest.json` тоже.

Сначала выполни «Общие правила» из `docs/Researcher v.2.0/basic-run-automation ( ТЗ на допиливание  схема V.2.0)/README.md` (пункты 1–4, 7 в части `docs/CHANGELOG.md` и 10). Проверь, что `BasicSchema.validate` принимает `run.stopMarks`, `run.onNoAnswer` и `run.repeat`.

## Что есть сейчас

- Схемы собирает `docs/Researcher v.2.0/basic/build-schemas.mjs`. Функция `schema(description, steps, taskLimit)` задаёт всем схемам одинаковое `run: { policy: 'auto', maxWords: 1000 }`.
- Цикл строит функция `cycle(endless)`: `4-cycle` — с шагами User, `4-cycle-endless` — без них. Карта вопроса — артефакт `map` участника `map` шага `r14`.
- Запросы ролей заканчиваются метками: «ТРЕВОГА: <код>» у контролёров и докладчика, «СТОП: <код>» у докладчика, «ЦИКЛ НЕ ВЫПОЛНЯЕТСЯ» в начале ответа координатора.
- Пакет цикла описан в `docs/Researcher v.2.0/data/README.md`, §4: раздел «ХОД» с номером цикла и остатком запросов, раздел «КАРТА ВОПРОСА» последним.

## Что сделать

1. В `build-schemas.mjs` дай функции `schema` четвёртый параметр `runExtra = {}`; объект `run` схемы — `{ policy: 'auto', maxWords: 1000, ...runExtra }`.
2. `4-cycle`: `stopMarks: ['ЦИКЛ НЕ ВЫПОЛНЯЕТСЯ']`. Метки тревоги здесь не ставь: в этой схеме последний шаг — окно решений User, и цикл обязан до него дойти, чтобы User прочитал донесение.
3. `4-cycle-endless`:

```js
{
  stopMarks: ['ТРЕВОГА:', 'СТОП:', 'ЦИКЛ НЕ ВЫПОЛНЯЕТСЯ'],
  onNoAnswer: 'skip',
  repeat: {
    carry: { step: 'r14', participant: 'map', artifact: 'map' },
    carryMarker: '=== КАРТА ВОПРОСА ===',
    maxPasses: 10,
    maxRequests: 250,
    ownerEvery: 5,
    carryMaxChars: 7500,
  },
}
```

4. Пересобери: `node "docs/Researcher v.2.0/basic/build-schemas.mjs"` из корня проекта. Сборка обязана закончиться строкой «Ошибок нет».
5. Документы `docs/Researcher v.2.0`:
   - `data/README.md`, §4: в разделе «ХОД» для непрерывного режима — метки `{заход+N}` и `{осталось запросов}`; число N вписывает User — это номер последнего пройденного цикла;
   - `process/04-endless-mode.md`: §3 — какое условие остановки чем исполняется (метка, пропуск, пределы, запись, документ для переноса); §5 — состояние каждого пункта;
   - `basic/README.md`, §2: строки о новых полях;
   - `operations/02-runbook.md`: как запустить непрерывный режим — выбрать папку документов, вставить пакет с метками счётчиков, запустить `4-cycle-endless`.

## Проверка

- Сборка проходит; в `4-cycle-endless.json` есть три новых поля, в `4-cycle.json` — только `stopMarks`.
- Обе схемы проходят `BasicSchema.validate` без ошибок.
- В остальных десяти схемах объект `run` не изменился.

## Готово, когда

Схемы пересобраны, документы названных разделов совпадают со схемами, коммит сделан.
