## Открытая проверка R1

Гипотеза: callback uncertain-terminal D1 может затронуть D2 на том же entry/session. Подтверждена только реакция на искусственную замену ID в harness; достижимость настоящими переходами не доказана. При закрытии записать трассу production guards либо сценарий воспроизведения и проверку исправления. Не объявлять дефект подтверждённым только по отсутствию проверки поля.
