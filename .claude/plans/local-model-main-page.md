# Локальная модель на главной странице (result_new.html)

Продолжение `.claude/plans/local-model-features.md` (реестр функций, режимы, окно, очередь — версия 2.81.1078).

## Концепция (согласована с User 2026-11-21)

ПРИНЦИП: локальная модель одна на всё приложение, функции у каждой страницы свои. На главной странице — такой же переключатель модели и такая же кнопка с окном функций, как на панели pipeline. Функции главной только читают вкладки моделей и ничего не нажимают; на отправку, приёмку ответов, Long и Get It не влияют.

НЕИЗМЕНЯЕМОЕ:
- Выбор модели общий: тот же ключ `localModelChoice`. Смена на одной странице меняет другую. «without LLM» — локальной модели нет нигде, приложение работает как раньше.
- Чекбоксы хранятся, как сейчас (`localModelFeatures`, по модели и функции). Окно каждой страницы показывает только функции и режимы своей страницы.
- Поведение панели pipeline не меняется.
- По умолчанию функции главной включены (режим Middle), как на pipeline.

## Решения ведущего

Размещение:
- Переключатель `#local-model-select` на `result_new.html` — в `.prompt-footer-right` слева от `.long-mode-toggle` (~стр. 182).
- Кнопка `#local-model-button` — в `.toolbar-cluster` (~стр. 259) слева от `#export-html-btn`. Скрыта при «without LLM», подпись — имя модели.
- Окно `#local-model-modal` — та же разметка, что на pipeline_panel.html (~стр. 454).
- Вкладка Local LLM (`#local-llm-tab`, `#local-llm-tabpanel`, `results/local-llm-tab.js`) — добавить в окно телеметрии главной страницы, как на pipeline_panel.html (~стр. 516–521). Log общий (`localModelState`).

Реестр: у каждой функции поле `page: 'pipeline' | 'main'`. Три нынешние — `pipeline`. Новые:

| id | Название в окне | Группа | Уровень | По умолчанию | Что делает |
|---|---|---|---|---|---|
| `main_stall_watch` | Наблюдение за зависшими вкладками | Наблюдение за вкладками | `log` | вкл | `createStallWatch` для моделей текущего запроса, пока у них нет финального ответа. Вывод — в Log. |
| `main_failure_look` | Разбор вкладки, не давшей ответа | Наблюдение за вкладками | `hint` | вкл | Когда модель закончила ошибкой, таймаутом или пустым ответом, `observeTab` её вкладки; `observationLine` показывается короткой строкой в карточке этой модели рядом со статусом. Строка снимается при новом запросе или очистке карточки. |

Режимы, «Свой» и показ уровней считаются по функциям страницы окна (`presetOf(model, page)`, `applyPreset(level, model, page)` — `applyPreset` меняет только функции этой страницы).

Вкладки моделей: страница получает tabId модели у фоновой части (найти существующий способ; если его нет — добавить в `background.js` одно сообщение только для чтения: имя модели → tabId её текущей вкладки). Ни отправку, ни сбор ответов не трогать.

Очередь: своя на каждой странице (как сейчас). Ollama сама обрабатывает запросы по одному.
